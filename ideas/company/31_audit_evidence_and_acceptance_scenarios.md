# บท 31 — ช่องว่างการตรวจรับที่ยังเหลือหลัง v1.3.0–v2.0.0

ฐานที่อ่าน: `main` commit `06ee226` (source release v2.0.0) รายงาน v1.3.0 ระบุการแก้ทุนหมุนเวียน การปลดล็อกเทคจากสินทรัพย์ การนับผลผลิต/รายได้ การเลือกลงทุนตามคอขวด และคุณสมบัติผู้ให้บริการ; source และ tests ปัจจุบันมีกรณีตรวจเหล่านี้แล้ว จึงย้ายรายการที่ทำเสร็จไป [project status](../../project_status_and_ai_onboarding.md)

## หลักฐานปัจจุบัน

- `docs/company/NPC_COVERAGE_MATRIX_V1.3.0.csv` มี 123 รายการที่ทำเครื่องหมาย `VERIFIED_V130` ตามรายงาน v1.3.0; ใช้เป็นหลักฐานของรอบนั้น ไม่แทนการทดสอบ v2.0.0 ทุกระบบ
- `COMPANY_SOURCE/test/product-depth-npc-board-v130.test.cjs` ตรวจเงื่อนไขเงินทุน ทรัพยากร/ความรู้ บริการ และความต่างของการตัดสินใจ CEO ตามบุคลิก
- `COMPANY_SOURCE/test/geopolitics-living-world-v200.test.cjs` ตรวจการเปลี่ยนรัฐบาล สงคราม สนธิสัญญา ผลต่อราคา/FX/ค่าขนส่ง/ดีมานด์ และพงศาวดาร
- ผลตรวจล่าสุดและขอบเขตแต่ละชุดอยู่ใน [สถานะโครงการ](../../project_status_and_ai_onboarding.md)

## การตรวจต่อยอดที่ยังมีประโยชน์

1. จำลองหลาย seed ระยะยาวและบริษัทหลายขนาด เพื่อดูการเกิด/ยุติไลน์ อัตราอนุมัติ ความล้มเหลว และเงินสดต่ำสุด
2. ทดสอบการยกเลิก/ล้มเหลวของธุรกิจทุกตระกูล: คืน reservation, custody, มัดจำ และเงินตามสัญญาโดยไม่จ่ายซ้ำ
3. ทดสอบการแข่งขันใช้คน เครื่อง และพื้นที่ร่วมกันระหว่างผลิต ซอฟต์แวร์ ขนส่ง และบริการในช่วงงานหนาแน่น
4. ตรวจผลกระทบภูมิรัฐศาสตร์ต่อเนื่องหลายรอบ ทั้งเหตุซ้อน/หมดอายุเหตุการณ์/ข้อตกลงใหม่ พร้อม S.audit และ Save.validate
5. ตรวจ UI/Edit Hub บนมือถือจริงว่าผู้เล่นเห็นเหตุผลทางธุรกิจและแก้สถานการณ์ได้โดยไม่ต้องรู้รหัสหรือ JSON
6. ตรวจความแตกต่างระหว่างผล benchmark ในรายงานแพตช์กับเครื่อง/Node รุ่นอื่นก่อนใช้เป็นคำรับรองประสิทธิภาพ

รายการเหล่านี้เป็นข้อเสนอสำหรับการตรวจในอนาคต ไม่ได้หมายความว่าทุกข้อเป็นบั๊กที่พบแล้ว หากเพิ่มข้อทดสอบให้ระบุ seed, สถานะเริ่ม, คำสั่ง และผลจริง ห้ามใช้เพียงข้อความใน catalog เป็นหลักฐานว่า NPC ทำงานได้
