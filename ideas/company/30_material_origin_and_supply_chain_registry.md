# บท 30 — 44 ข้อเสนอทรัพยากรและวัตถุดิบที่ยังเหลือ พร้อมเส้นทางกำเนิด
สถานะฐาน main v2.1.0: ตัดออก/รวมชื่อที่มีอยู่แล้ว 16 แถว ได้แก่ วัตถุดิบที่เพิ่มใน v1.3.0 (`iron_ore`, `wheat_seed`, `wheat_grain`, `wheat_flour`, `pharma_saline_water`), วัตถุดิบที่เพิ่มใน v2.1.0 (`coke_reducing_flux`, `alumina_billet` ซึ่งครอบคลุม `alumina` และ `aluminium_ingot`, `structural_steel_plate` ซึ่งครอบคลุม `steel_coil`, `mineral_slag_mud`, `nickel_cobalt_matte`, `aluminum_extrusion_profile`), วัตถุดิบเดิมใน catalog (`bauxite_ore`, `raw_water_m3`) และชื่อเสนอที่ซ้ำความหมายกับ `copper_iron_ore`, `silica_bauxite_ore`, `crude_petro_feedstock`, `ambient_air_gas`, `nitrogen_ammonia`, `diesel_liter`, `npk_fertilizer` เหลือ 44 ข้อเสนอ รายการที่เหลือยังผสมแนวทางใช้ของเดิม การแยกเกรด/วัตถุดิบ และของใหม่ ไม่ใช่ 47 ID ใหม่ที่ต้องเพิ่มทั้งหมด `pharma_water` ยังเป็นข้อเสนอสารตั้งต้นที่ต้องแยกให้ชัดจาก `pharma_saline_water` ซึ่งเป็นวัสดุในเกมแล้ว ต้องเทียบ catalog ก่อนตั้ง ID ทุกครั้ง

ข้อเสนอที่ยังเหลือเป็นจุดเริ่ม registry ไม่ใช่ BOM ครบทุกผลิตภัณฑ์ รายละเอียดรายการที่มีแล้วและหลักฐานอยู่ใน [project status](../../project_status_and_ai_onboarding.md) ก่อนประกาศว่าไลน์ใดพร้อม ต้องตรวจสารตั้งต้น/เครื่องมือ/ของเสียที่ยังขาด เช่น chemical reagents, ตัวเร่ง, electrolyte, semiconductor consumables และชุดชีวภาพ ไม่ให้ชื่อรวมซ่อนขั้นตอนที่ยังผลิตไม่ได้

## กราฟต้นทางและกติกา
1. ธรรมชาติ → เข้าถึงแหล่ง/สัมปทาน → ขุด/สูบ/เก็บเกี่ยวที่คิดแรงงาน เครื่องมือ เวลา พลังงาน → วัตถุดิบต้นทางพร้อมใช้ ถ้าซื้อจากภายนอกก็มี supplier และ lead time ไม่ใช่จ่ายแล้วปรากฏทันที
2. เมล็ด/กล้า/ท่อนพันธุ์ + ที่ดิน + น้ำ + ธาตุอาหาร + เวลา → พืชผล → คัดส่วนขยายพันธุ์/ขาย/แปรรูป การเก็บพันธุ์ไม่ทำสำเนาจากสินค้าที่ขายไปแล้ว
3. ฝูงสัตว์ + อาหารสมดุล + น้ำ + การดูแล → ผลผลิต + มูล มีสุขภาพและกำลังผลิต ไม่รีดนมได้ไม่สิ้นสุดจากสัตว์ไม่มีอาหาร
4. ไม้ปลูก → ตัด → ตอ/พื้นที่พัก → ปลูกทดแทน → รอโต ไม้จากสวนไม่เป็นแร่ธรรมชาติ
5. น้ำมันดิบ → กลั่น → แนฟทา/เชื้อเพลิงและส่วนอื่น → เคมี/พอลิเมอร์ แนฟทาไม่อยู่ในแหล่งใต้ดินในฐานะผลผลิตกลั่นสำเร็จ
6. อากาศ → N2; น้ำ+พลังงาน → H2; N2+H2 → NH3 → แม่ปุ๋ย N; แร่ P/K → แม่ปุ๋ย P/K; N+P+K → NPK ห้ามสร้าง N จากหิน P/K+น้ำ
7. ของเสียต้องมีต้นทางรับเข้า → คัด/คืนสภาพ → วัสดุเกรดหนึ่ง + reject/มวลสูญ ไม่รีไซเคิลวนแล้วได้วัสดุมากขึ้นหรือได้เงินค่ารับกากโดยไม่มีลูกค้า

## แยกมิติให้ชัด
resourceClass บอกกำเนิดและธรรมชาติ; processTier บอกระดับแปรรูป; qualityGrade บอกการใช้ได้; form/unit บอกกายภาพ; technologyRequired บอกสิทธิผลิต ห้ามใช้เลข tier ตัวเดียวสรุปทุกมิติ
วัตถุดิบแปรรูปทุกชนิดต้องมีอย่างน้อยหนึ่งสูตรผลิตที่เชื่อมถึงต้นทางจริง และ supplier เส้นทางซื้อเมื่อยังทำเองไม่ได้ ขั้นตอนลึกมากอาจใช้ process model ย่อที่เก็บอินพุต/ข้อจำกัดสำคัญ ไม่ให้ทางย่อสร้างธาตุหรือข้ามความรู้
เมล็ดพันธุ์เป็นวัฏจักรชีวภาพที่มี initial stock จากบัญชีเริ่มต้นหรือการซื้อได้ ไม่บังคับกราฟทั้งหมดเป็น DAG จนห้ามเก็บเมล็ด แต่ต้องไม่มีวงจรสร้างมวล/เงินฟรี

## ซื้อหรือผลิตเอง
ไม่มีเทคผลิต chip ไม่ได้แปลว่าห้ามประกอบ gateway ถ้าซื้อ chip ผ่าน supplier ที่มีคุณภาพและมีเทคประกอบได้ มีเทคผลิตเองก็อาจซื้อเพราะล็อตเล็ก เครื่องไม่ว่าง หรือ cost สูงกว่า ให้คิด landed cost, MOQ, lead time, defect, freight, credit และความเสี่ยงขาดส่ง
ผลิตแล้วสามารถขาย B2B ใช้ต่อ หรือเก็บตามข้อจำกัด ไม่ใช่วัตถุดิบที่มีในสูตรแต่ไม่มีผู้ซื้อ/ไม่มี demand เฉพาะวัสดุอันตราย/ทางการแพทย์ต้องมีตลาดและมาตรฐานตรงเกรด

## Schema แนะนำสำหรับแต่ละรายการ
id, label, unit, originClass, processTier, qualityGrades, physicalProperties, shelfLife, storageConditions, supplierOptions, processRecipeIds, techCapabilityIds, equipmentRequirements, demandSources, byproducts, wasteTreatment, tradeRestrictions และบัญชี movement ที่ตามกลับได้
วัตถุดิบตั้งต้นอ้างถึง source asset/stock/purchase; process output อ้างถึง batch; การขายหัก physical stock และลงเงินตามกำหนดจริง ใช้หน่วย batch ได้ถ้าประกาศอัตราแปลง ไม่อ้าง mass conservation ที่ไม่ได้ตรวจหน่วย
