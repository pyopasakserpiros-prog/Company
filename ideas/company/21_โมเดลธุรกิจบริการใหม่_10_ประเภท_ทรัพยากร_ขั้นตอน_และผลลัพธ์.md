# ข้อเสนอธุรกิจบริการที่ยังเหลือ 7 รูปแบบ

> **สถานะฐาน main v2.0.0:** บริการวิศวกรรม B2B 3 แบบ (`calibration_lab`, `field_maintenance`, `industrial_recycling`) และบริการต่อยอด 3 แบบ (`battery_second_life_lab`, `returnable_pallet_pool`, `cold_storage_3pl`) ถูกย้ายไป [project status](../../project_status_and_ai_onboarding.md) แล้ว เอกสารนี้เหลือข้อเสนออีก 7 แบบจากคลังเดิม ไม่ใช่ข้อกำหนดว่าต้องทำครบ
>
> ตัวเลขราคา/ทุนที่ปรากฏในตัวอย่างเอกสารเก่าต้องตรวจและคำนวณใหม่จากสมดุลเกม ห้ามใช้เป็นราคาจริง

## 1. ให้เช่าเครื่องมือและเครื่องจักร

**ต้องมี:** asset รายชิ้นที่มีสภาพ/ตำแหน่งจริง ลานเก็บ ช่างตรวจ ซ่อม และเงินซื้อหรือเงินประกันเช่า

**ขั้นตอน:** ตรวจพร้อมใช้ → รับจองช่วงเวลา → ตรวจเครดิต/มัดจำ → ส่งมอบพร้อมสภาพก่อนเช่า → รับคืน/ตรวจ → หักค่าเสียหายตามหลักฐาน → ซ่อมหรือปล่อยเช่ารอบใหม่

**ผลและความเสี่ยง:** รายได้ตามเวลาที่เช่าจริง; downtime, ความเสียหาย, การจองซ้อน และมัดจำที่ต้องคืนต้องลงบัญชี

## 2. ซักรีดอุตสาหกรรมและผ้าลินินหมุนเวียน

**ต้องมี:** เครื่องซัก/อบ/รีด น้ำและพลังงาน สารซักล้าง QC พื้นที่แยกผ้าสกปรก/สะอาด รถรับส่ง และทะเบียนผ้าที่มีเจ้าของ

**ขั้นตอน:** รับ/นับ/คัด → จองเครื่อง → ซัก/อบ/รีด → ตรวจจำนวนและความสะอาด → ส่งคืน/บันทึกสูญหาย → ออกบิลตามหน่วยสัญญา

**ผลและความเสี่ยง:** งานซักซ้ำกิน capacity และวัตถุดิบ; แยกผ้าลูกค้าจาก asset pool บริษัทและงานปลอดเชื้อทางการแพทย์

## 3. บริการน้ำอุตสาหกรรมและบำบัดน้ำเสีย

**ต้องมี:** แหล่งน้ำและ capacity, ถัง/ปั๊ม/กรอง/บำบัด, สารเคมี, ห้องทดสอบ, ผู้ปฏิบัติงาน และปลายทางตะกอน

**ขั้นตอน:** รับตัวอย่าง/วัดโหลด → เสนอขอบเขต → รับและพักน้ำเสีย → บำบัด → ตรวจผล → ส่งน้ำใช้ซ้ำหรือกำจัดตะกอน → ออกบิล

**ผลและความเสี่ยง:** คิดงานตามปริมาตรและภาระมลพิษ; น้ำไม่ผ่านห้ามขายเป็นเกรดสูง ต้องคิด reject, sludge และน้ำสูญเสีย

## 4. ศูนย์ฝึกอาชีพสำหรับบริษัทภายนอก

**ต้องมี:** ผู้สอนที่มีทักษะ สถานี/เครื่องมือที่ปลอดภัย สื่อฝึก เวลาที่กันจากงานผลิต และเกณฑ์วัดความชำนาญ

**ขั้นตอน:** ลูกค้าแจ้งทักษะ → ตรวจช่องว่าง → จัดรอบและผู้สอน → ฝึก/ประเมิน → รายงานผล → วางบิล

**ผลและความเสี่ยง:** รายได้ต่อรอบพร้อมทักษะภายนอกแกนที่ตรวจได้; ผู้สอนไปสอนทำให้งานเดิมลดลง และใบเข้าร่วมไม่เท่ากับสอบผ่าน

## 5. โรงแรมธุรกิจและศูนย์ประชุม

**ต้องมี:** ห้อง/พื้นที่ประชุมที่จองแยกได้ พนักงานต้อนรับและทำความสะอาด ระบบบำรุงรักษา น้ำ/ไฟ และผ้าลินิน

**ขั้นตอน:** เสนอราคา/รับจอง → ตรวจห้องและมัดจำ → ให้บริการ → check-out/ตรวจ → คิดค่าจริง/คืนส่วนเกิน → ทำความสะอาดก่อนขายรอบใหม่

**ผลและความเสี่ยง:** รายได้จากห้องที่เข้าพักจริงเท่านั้น; ห้องว่างหรือไม่พร้อมใช้ไม่สร้างรายได้ และมัดจำยังมีภาระคืน

## 6. ผู้ค้าส่งและตัวแทนจำหน่าย

**ต้องมี:** supplier ที่ส่งจริง โกดัง QC รับเข้า เงินทุนหมุน สต็อกตามล็อต ฝ่ายขาย เครดิตลูกค้า และขนส่ง/ผู้รับจ้าง

**ขั้นตอน:** เก็บ demand → ขอราคา/วาง PO → รับและตรวจ → บริหารสต็อก → รับ order → จอง/หยิบ/ส่ง → เก็บเงิน/จัดการคืน

**ผลและความเสี่ยง:** กำไรจากส่วนต่างและบริการจัดหา; ต้นทุนสินค้าต้องตัดเมื่อขาย สต็อกล้าสมัย ลูกหนี้ และเงินจมกระทบเงินสด

## 7. ติดตั้งและดูแลระบบพลังงานให้ลูกค้า

**ต้องมี:** วิศวกร/ช่าง เครื่องมือทดสอบ อุปกรณ์ที่ซื้อจริง การสำรวจพื้นที่ สัญญาเจ้าของอาคาร และทีมบำรุงรักษา

**ขั้นตอน:** สำรวจโหลด/พื้นที่ → ออกแบบ/เสนอ → จองวัสดุและกำลังคน → ติดตั้ง/ทดสอบ → ส่งมอบ → ซ่อมบำรุงหรือคิดค่าพลังงานตามสัญญา

**ผลและความเสี่ยง:** แยกรายได้ติดตั้ง บริการ และพลังงาน; ผลิต/ขายพลังงานต้องมีระบบและลูกค้ารับซื้อจริง ไม่ซ้ำกับพลังงานที่บริษัทใช้เอง

## กติกาที่ใช้กับข้อเสนอทั้งหมด

- ทุกบริการต้องมี demand/ลูกค้า คู่สัญญา คน เครื่องมือ วัตถุดิบ และกำลังที่พร้อมก่อนเริ่มงาน
- จองคน/asset/พื้นที่ก่อนรับงาน คืน reservation เมื่อยกเลิก และรักษา custody ของทรัพย์สินลูกค้า
- แยกมัดจำ ลูกหนี้ รายได้ที่รับรู้ และเงินสด; ไม่สร้างรายได้รายวันจากสินทรัพย์ที่ไม่ได้ทำงาน
- ให้ NPC เลือกลงทุน ทดลอง จ้างช่วง พัก หรือปฏิเสธตามข้อมูลและนิสัย พร้อมบันทึกเหตุผลที่ผู้เล่นอ่านเข้าใจ
