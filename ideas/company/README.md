# คลังข้อเสนออนาคต — Company Simulation

เอกสารในโฟลเดอร์นี้เป็นข้อเสนอสำหรับพัฒนาต่อ ไม่ใช่รายการที่ต้องทำครบทุกข้อ การพิจารณาสิ่งที่เกมมีแล้วให้ยึด source และ [สถานะโครงการ](../../project_status_and_ai_onboarding.md) เป็นหลัก

## วิธีอ่านสถานะคลังไอเดีย

- **ย้ายไป status แล้ว:** ส่วนที่ยืนยันว่ามีจริงถูกนำออกจากเอกสารไอเดียและสรุปไว้ใน project status/รายงานแพตช์
- **คงไว้เป็นข้อเสนอ:** ระบบยังไม่ครบหรือเป็นการต่อยอด ต้องตรวจ source ล่าสุดก่อนทำ
- **เอกสารรุ่นเก่า 01–18 และ 25–27:** มีแนวคิดที่อาจทับซ้อนระบบปัจจุบันและข้อเสนอที่ยังไม่ทำครบ ใช้เป็นคลังอ้างอิง ห้ามสรุปจากชื่อบทว่าเสร็จหรือไม่เสร็จทั้งบท ให้เทียบกับ status รายระบบก่อนหยิบไปทำ

## ข้อเสนอและส่วนที่ยังเหลือ

| บท | เนื้อหาในคลังปัจจุบัน | สถานะหลังเทียบ main v2.0.0 |
|---|---|---|
| 01–12 | บุคลากร สวัสดิการ การผลิต อาชีพ เศรษฐกิจส่วนตัว ธุรกิจ | เอกสารเก่าผสมระบบที่มีบางส่วนกับข้อเสนอระยะยาว; ตรวจเป็นรายข้อก่อนทำ |
| 13–18 | ข้อมูลไม่สมบูรณ์, KPI, รุ่นสินค้า, ความต่อเนื่อง, การเข้าถึง, มาตรฐาน/ความเข้ากันได้ | คงเป็นข้อเสนอ; ตรวจความเกี่ยวข้องกับระบบล่าสุดก่อนเริ่ม |
| 19 | กองรถขนส่ง B2B | ย้ายวงจรธุรกิจหลักไป status แล้ว; เหลือข้อเสนอต่อยอดเส้นทาง/สัญญา/วงจรชีวิตรถ |
| 20 | ซอฟต์แวร์และแอป | ย้ายวงจรโครงการและ SaaS หลักไป status แล้ว; เหลือข้อเสนอต่อยอดหลังเปิดใช้/ผู้ใช้/โฮสต์ |
| 21 | ธุรกิจบริการเพิ่มเติม 10 แบบ | 3 รูปแบบเดิมถูกรวมใน 6 บริการที่เกมมี; เหลือ 7 แบบที่ยังเป็นข้อเสนอ |
| 22 | ธุรกิจต้นน้ำเพิ่มเติม 7 สาย | คงเป็นข้อเสนอ; บางวัตถุดิบ/ขั้นการผลิตมีแล้ว ให้ตรวจ ID และห่วงโซ่ก่อนเพิ่ม |
| 25–27 | วัฒนธรรมองค์กร, utilities/วิกฤต, ภาพขนส่ง/อากาศ/ที่จอดรถ | คงเป็นข้อเสนอหรือการต่อยอด; มีบางส่วนอาจทับกับระบบพื้นฐาน |
| 28 | ผลิตภัณฑ์/ไลน์ธุรกิจ 96 รายการ | ย้ายสินค้าที่มีแล้ว 8 รายการออก; เหลือข้อเสนอ 88 รายการใน [บท 28](28_product_families_and_business_depth.md) |
| 29 | การตัดสินใจของผู้บริหาร/NPC | ระบบเงินสดอิสระ, gates และ decision ledger ย้ายไป status; เหลือบทบาทบอร์ด/แผนเตรียม/ทบทวนผล |
| 30 | ทะเบียนวัตถุดิบ 60 รายการ | ตัด/รวมวัตถุดิบที่มีหรือซ้ำแล้ว 13 แถว รวม ID ใหม่ 7 ชนิด; เหลือ 47 รายการใน [บท 30](30_material_origin_and_supply_chain_registry.md) |
| 31 | Audit/coverage และ acceptance tests | ประเด็น v1.3 ที่แก้แล้วถูกย้ายไป status; เหลือข้อเสนอการตรวจระยะยาวใน [บท 31](31_audit_evidence_and_acceptance_scenarios.md) |
| 32 | ข้อเสนอเสริมและตัวอย่างมติ | ย้าย capability domains, budget pools และบริการที่ทำแล้วออก; คงเฉพาะส่วนต่อยอดใน [บท 32](32_additional_design_proposals_and_decision_examples.md) |

## เอกสารที่ย้ายออกหลังทำครบ

- **บท 23 — ต้นน้ำแท้จริง/วงจรเกษตร:** หลักกำเนิดวัตถุดิบ เมล็ดพันธุ์ น้ำ/ปุ๋ย/ดิน และการเก็บเกี่ยวถูกรวมในกฎ [AGENTS.md](../../AGENTS.md) และระบบในสถานะโครงการ
- **บท 24 — 8 โมเดลธุรกิจ:** สรุปไว้ในสถานะโครงการและรายงาน v1.2.0
- **บท 33 — ภูมิรัฐศาสตร์โลก:** สรุปไว้ในสถานะโครงการและรายงาน v2.0.0

## ส่งต่องาน

ไอเดียเป็นข้อเสนอที่ปรับ รวม ตัด หรือแตกเป็นแบบที่ดีกว่าได้ ให้ทีมพัฒนาคิดเพิ่มเติมเอง ตรวจ source/test ก่อนอ้างว่ามีหรือไม่มี และย้ายออกจากคลังเฉพาะส่วนที่ยืนยันว่าทำงานจริงแล้ว
