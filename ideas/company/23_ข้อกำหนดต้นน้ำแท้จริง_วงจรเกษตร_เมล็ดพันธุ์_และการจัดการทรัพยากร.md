# ข้อกำหนดจากผู้ใช้: ต้นน้ำแท้จริง วงจรเกษตร เมล็ดพันธุ์ และการจัดการทรัพยากร

> คำกำชับล่าสุดของผู้ใช้สำหรับ Gemini · 11 พฤศจิกายน 2026
>
> **หลักการในบทนี้เป็นข้อกำหนดจากผู้ใช้ ไม่ใช่ข้อเสนอให้ข้ามได้** ให้ใช้เหนือการจัด Tier/สูตร/ตัวอย่างเดิมที่ขัดกัน ส่วนวิธีออกแบบ โครงสร้างข้อมูล และตัวเลขเป็นข้อเสนอที่ Gemini ปรับปรุงเองได้ตามกฎเหล็ก
>
> ยังเป็นเอกสารมอบหมายงาน ไม่ได้แก้ซอร์สหรือยืนยันว่าระบบนี้มีแล้ว

## 1. คำนิยามที่ต้องแก้ให้ตรง

**ต้นน้ำแท้จริง** คือทรัพยากรธรรมชาติหรือแหล่งทรัพยากรก่อนผ่านการเพาะเลี้ยง/ผลิต/แปรรูป เช่น แหล่งแร่ หิน ทราย น้ำดิบ อากาศ และแหล่งพลังงานธรรมชาติ โดยมีการเข้าถึงและข้อจำกัดตามชนิด

น้ำตาล แป้ง กระดาษ เมล็ดพลาสติก โลหะถลุง และก๊าซที่แยก/บรรจุแล้วเป็นผลผลิตจากกระบวนการ ไม่ใช่ต้นน้ำแท้จริง แม้โรงงานของบริษัทจะเลือกซื้อแทนผลิตเองก็ตาม

**ข้าวก็ไม่ใช่ต้นน้ำแท้จริง:** ข้าวเปลือกเกิดจากการเพาะปลูก ข้าวสารเกิดจากการสี และแป้งข้าวเกิดจากการโม่ ผลผลิตหนึ่งชนิดอาจเป็นวัตถุดิบสำหรับกระบวนการถัดไปได้ แต่ไม่ได้กลายเป็นทรัพยากรธรรมชาติเริ่มต้นเพราะเรียกว่า “วัตถุดิบ”

แยกอย่างน้อยสี่ความหมายออกจากกัน: แหล่งธรรมชาติ, ผลผลิตชีวภาพ, วัตถุดิบแปรรูป/ชิ้นส่วน, และสินค้าหรือบริการปลายทาง การเป็น input ของสูตรไม่ใช่หลักฐานว่าเป็นต้นน้ำจริง

## 2. ไม่ให้แหล่งทรัพยากรผลิตสินค้าสำเร็จฟรี

- เหมืองมีปริมาณสำรอง เกรด การเข้าถึง คน เครื่องมือ เวลา พลังงาน และของเสีย การซื้อเหมืองไม่เพิ่มโลหะถลุง/ชิปเข้าคลังฟรีทุกวัน
- แร่ที่ขุดได้ต้องผ่านคัด/แต่งแร่ ถลุง/ทำให้บริสุทธิ์ และขึ้นรูปตามชนิดก่อนใช้ ไม่ใช้แร่รวมแทนทุกเกรดของโลหะหรือแก้วได้ทันที
- ป่าไม้ธรรมชาติมี stock ที่ลดลงและการฟื้นตัวตามเวลา ป่าปลูกมีปลูก ดูแล และรอรอบตัด ไม่เสกไม้ เยื่อ และกล่องจาก asset เดียวโดยไม่เกิดขั้นตอน
- น้ำมีแหล่ง ปริมาณ/อัตราไหล คุณภาพ สิทธิ์/ขีดจำกัดการใช้ และต้นทุนสูบ/บำบัด; น้ำเสียไม่หายไปโดยไม่มีทางจัดการ
- อากาศเป็น intake ภายนอกที่วัดตามกำลังเครื่องและพลังงาน ไม่ต้องจำลองว่าอากาศทั้งโลกหมด แต่ก๊าซแยกเกรดไม่เกิดฟรี
- แสงอาทิตย์/ลมเป็นพลังงานไหลเข้าตามสภาพแวดล้อม กำลังอุปกรณ์และการแปลงจำกัด พลังงานเก็บได้ต้องมี storage และการสูญเสีย

ทรัพยากรแต่ละชนิดไม่จำเป็นมีข้อจำกัดเหมือนแร่: แยก finite stock, renewable stock และ environmental flow ให้เหมาะสม ห้ามทำให้ทรัพยากรไม่จำกัดทุกชนิดหรือบังคับอากาศมีการขุดเหมือนเหมือง

## 3. วงจรเกษตรที่ต้องมีเมื่อเพิ่มธุรกิจเกษตร

1. **ที่ดินและสภาพตั้งต้น:** ขนาดแปลง ดิน ความชื้น ธาตุอาหาร การระบายน้ำ ภูมิอากาศ และแหล่งน้ำ มีที่มา ไม่ใช่ซื้อฟาร์มแล้วได้ข้าวทันที
2. **เมล็ดพันธุ์:** เลือกชนิด/พันธุ์ จำนวน ความงอก คุณภาพและแหล่งซื้อหรือผลผลิตที่เก็บไว้ ระบุ stock เริ่มต้นที่สร้างโลกอย่างชัดเจน
3. **เตรียมแปลง:** ใช้คน เครื่องมือ เวลา และวัสดุที่เกี่ยวข้อง มีพื้นที่จำกัดและแปลงที่อยู่ระหว่างงานรับงานซ้อนไม่ได้
4. **ปลูก:** หักเมล็ดออกจากคลังและจองพื้นที่ในเวลาปลูก เกิด cohort/แปลงปลูกที่มีวันเริ่มและสถานะ
5. **ดูแลระหว่างเติบโต:** น้ำ ธาตุอาหาร/ปุ๋ย แรงงาน พลังงาน สภาพอากาศ วัชพืช/โรค/แมลงตามขอบเขตที่เลือก ขาด input มีผลจริงต่อการเติบโต/ผลผลิต
6. **เก็บเกี่ยว:** ใช้แรงงาน เครื่องมือและเวลา ผลผลิตคำนวณจากพื้นที่ พันธุ์ สภาพ และการดูแล มีการสูญเสียและผลพลอยได้ที่ระบุ
7. **คัดและเก็บ:** แยกผลผลิตสำหรับบริโภค/ขาย/แปรรูปกับส่วนที่เหมาะเป็นเมล็ดพันธุ์ ตรวจความชื้น คุณภาพ และอายุเก็บ
8. **ปลูกรอบต่อไป:** เมล็ดที่เก็บไว้เข้าคลังพันธุ์จริงและถูกใช้รอบใหม่ ดินและทรัพยากรมีสถานะต่อเนื่อง ไม่รีเซ็ตให้สมบูรณ์ทุกครั้งหลังเก็บเกี่ยว

รอบปลูกต้องใช้เวลา simulation จริง ปรับสเกลให้เล่นได้แต่ต้องคงลำดับและเหตุผล ห้ามเมล็ดหนึ่งหน่วยสร้างผลผลิตแล้วนำเมล็ดเดียวกันไปปลูกซ้ำทันทีโดยไม่มีการหักใช้

## 4. เมล็ดจากผลผลิตและความเป็นจริงทางชีวภาพ

- สำหรับข้าว สามารถคัดส่วนของ **ข้าวเปลือกที่ยังเหมาะต่อการงอก** เก็บเป็นเมล็ดพันธุ์และปลูกใหม่ ไม่ใช้ข้าวสารที่สีแล้วหรือแป้งกลับไปปลูก
- แบ่งผลเก็บเกี่ยวเป็นขาย แปรรูป เก็บกิน เก็บพันธุ์ และสูญเสีย ผลรวมต้องไม่เกินปริมาณที่เก็บเกี่ยวจริง การกันพันธุ์ไว้ลดจำนวนที่ขายได้
- ความงอก/คุณภาพเสื่อมตามสภาพและอายุเก็บ การคัด/ทดสอบใช้เวลาและอาจมีตัวอย่างสิ้นเปลือง ไม่รับประกันทุกเมล็ดงอก
- ชนิดที่ขยายพันธุ์ด้วยต้นกล้า ท่อนพันธุ์ หรือส่วนพืช ให้ใช้วิธีเหมาะกับพืชนั้น ไม่บังคับทุกชนิดเป็นเมล็ดแบบข้าว
- พันธุ์ลูกผสม/ข้อกำหนดสิทธิ์อาจมีผลต่อการใช้รุ่นถัดไป แต่ไม่เหมารวมว่าทุกเมล็ดลูกผสมเป็นหมันหรือว่าห้ามเก็บพันธุ์ทุกกรณี
- วงจรนี้ไม่ต้องย้อนถึงกำเนิดสิ่งมีชีวิต: seed stock เริ่มต้น/ผู้ขาย/ต้นพันธุ์เดิมเป็นเงื่อนไขตั้งต้นที่ระบุได้ จากนั้นทุกการเพิ่มจำนวนต้องผ่านวงจรชีวภาพที่ใช้พื้นที่ เวลา และทรัพยากร

## 5. ปุ๋ย ดิน น้ำ และผลพลอยได้

มี nutrient budget ของแปลงอย่างน้อยระดับที่อธิบายได้ การเก็บเกี่ยวดึงธาตุอาหารออกจากดิน การเติมปุ๋ยหรือวัสดุปรับปรุงต้องมีต้นทุนและผลตามความเหมาะสม ไม่เพิ่มผลผลิตไม่จำกัดจากการใส่ซ้ำ

ปุ๋ยก็ผลิตได้ ซื้อได้ ขายได้ และมีต้นทาง เช่น หินฟอสเฟต/แร่โพแทชผ่านกระบวนการให้เป็นวัตถุดิบตามเกรด หรือธาตุอาหารไนโตรเจนที่ได้จากกระบวนการผลิตที่ใช้วัตถุดิบ/พลังงาน ไม่ใช่แปะ `nitrogen_nutrient` เป็นทรัพยากรธรรมชาติฟรี ใช้การจำลองกระบวนการอุตสาหกรรมระดับสูง ไม่จำเป็นจำลองรายละเอียดเคมีทุกขั้น

เศษพืช/มูลสัตว์ที่มีจริงอาจเข้ากระบวนการหมักเป็นปุ๋ยอินทรีย์ ต้องใช้พื้นที่ เวลา การจัดการ ความชื้น และมีการสูญเสีย/คุณภาพ ไม่ใช่แปลงเศษทุกชนิดเป็นปุ๋ยใช้ได้ทันที วงจรคืนธาตุอาหารไม่รับประกันคืนครบ 100%

เพิ่มทางเลือกตามความเหมาะสม เช่น หมุนเวียนพืช พักแปลง ปรับอินทรียวัตถุ และปรับระบบน้ำ เกษตรกร NPC ต้องประเมินเงิน คน น้ำ ดิน ฤดูกาล และความเสี่ยงก่อนปลูก/ขยาย ไม่ปลูกทุกพื้นที่ตลอดเวลาโดยไม่มีข้อจำกัด

หากเพิ่มปศุสัตว์ให้มีต้นพันธุ์/ฝูง อาหาร น้ำ พื้นที่ การดูแล การสืบพันธุ์และระยะเติบโต น้ำนมไม่ใช่ทรัพยากรที่ปรากฏฟรีเมื่อซื้อฟาร์ม

## 6. ทุกขั้นผลิตได้ ขายได้ หรือใช้ต่อได้ตามคุณสมบัติ

ตัวอย่างห่วงโซ่ที่ต้องอธิบายได้:

- **ข้าว:** ที่ดิน/ดิน + เมล็ดพันธุ์ + น้ำ + ธาตุอาหาร + คน/เครื่อง/เวลา → ข้าวเปลือก → คัดบางส่วนเป็นพันธุ์รอบใหม่ / ขาย / สี → ข้าวสาร + รำ + แกลบตาม yield → โม่/แปรรูปตามชนิด
- **น้ำตาล:** ท่อนพันธุ์อ้อย + แปลง/ดิน + น้ำ + ปุ๋ย + เวลา → อ้อย → สกัด/แปรรูป → น้ำตาล + กาก/ผลพลอยได้ที่ระบุ → เครื่องดื่ม/อาหาร ไม่เริ่มจากน้ำตาลเป็น T0
- **แป้ง:** ผลผลิตพืชที่เหมาะ → คัด/ทำความสะอาด/สีหรือกระบวนการตามชนิด → โม่/สกัด → แป้ง → อาหาร/ผลิตภัณฑ์อื่น แยกแป้งข้าวกับแป้งสาลีเมื่อคุณสมบัติต่างกัน
- **กระดาษ:** ป่า/ต้นปลูกที่มีอายุหรือเศษกระดาษจากการใช้จริง → ไม้/เส้นใยหรือ recovered fiber → เยื่อ → กระดาษ → กล่อง การตัดต้นปลูกทำให้ stock ต้นไม้ลดลงและต้องปลูกทดแทน
- **โลหะ:** แหล่งแร่ → ขุด/แต่งแร่ → วัตถุดิบเกรดที่เหมาะ → ถลุง/ทำบริสุทธิ์ → โลหะ → ชิ้นส่วน → สินค้า พร้อมกากแร่และต้นทุนทุกขั้น

ผลผลิตกลางควรเป็นสินค้าที่ซื้อขาย B2B หรือใช้ต่อได้เมื่อมีตลาด เกรดและหน่วยตรงกัน บริษัทเลือก make-or-buy ได้ ไม่บังคับผู้เล่นสร้างทุกโรงต้นน้ำเอง แต่การซื้อไม่ใช่ข้ออ้างว่า item นั้นไม่มีที่มาหรือผลิตไม่ได้ในแบบจำลองโลก

## 7. แยกประเภททรัพยากรออกจากลำดับการแปรรูป

เสนอ `resourceOrigin`/`resourceClass` แยกจาก `processingStage` หรือ Tier เดิม เพราะวงจรชีวภาพไม่ใช่ DAG เส้นตรง: เมล็ด → แปลงปลูก → ผลผลิต → เมล็ดรอบใหม่เป็นวงจรที่ถูกต้องเมื่อผ่านเวลาและต้นทุน

ใช้ job graph ที่มีเวลา/ข้อจำกัดสำหรับวงจรเพาะปลูก คงการตรวจวงจรสูตรที่ทำให้ craft ฟรีได้ ห้ามปิดตัวตรวจ cycle ทั้งหมดเพียงเพื่อให้เมล็ดปลูกใหม่ได้

ราย item ควรมีหน่วย แหล่งกำเนิด กระบวนการที่ผลิตได้ suppliers/buyers เกรด อายุเก็บ วิธีใช้ และของเสีย แหล่งธรรมชาติมี state ของแหล่ง แปลงเกษตรมี state ของแปลง ต่างจากจำนวนถุงที่อยู่ในคลัง

## 8. ตรวจและแก้ความหมายเดิมที่ไม่ตรง

ตัวอย่างซอร์สปัจจุบันมี `paddy_grain` ถูกจัด T0 และ key รวมความหมาย เช่น `fresh_milk_soy`, `silica_bauxite_ore`, `raw_cane` หรือ `natural_latex` ที่ชื่อครอบคลุมหลายอย่าง ให้ Gemini ตรวจจริงแล้วแยก/จัดใหม่เฉพาะที่จำเป็นเพื่อให้สูตรและเกรดถูกต้อง ไม่ใช้ชื่อเดิมเป็นข้อบังคับให้ทำวงจรผิด

สิทธิ์ปรับระบบนี้ไม่รวมการแก้ Human Core หรือ hash ห้ามเปลี่ยนหน่วย/ความหมายของ key เดิมโดยไม่ตรวจผลต่อ BOM, stock, external assets, suppliers/buyers, audit, save, tests และ UI ทั้งชุด เซฟข้ามแพตช์ยังใช้กฎเดิม ไม่ต้องเพิ่ม migration เก่าอย่างไม่มีเหตุผล

หากเอกสารเก่าหรือ reference skills เรียกสินค้าที่แปรรูปแล้วว่า T0 หรือแสดงผลผลิต asset “ฟรีต่อวัน” ให้ใช้คำกำชับล่าสุดนี้ปรับการออกแบบและอัปเดตเอกสารส่วนที่ทำจริง ไม่ยึดตัวเลขเก่าเพื่อรักษาความผิดเดิม

## 9. เกณฑ์ตรวจรับและรายงานที่ต้องเพิ่ม

- มีตารางแหล่งธรรมชาติ → การสกัด/เพาะปลูก → สินค้ากลาง → สินค้าปลายทาง สำหรับธุรกิจที่ทำจริง และระบุส่วนที่จำลอง/ย่อ/ยังไม่ทำอย่างตรงไปตรงมา
- ไม่มีน้ำตาล แป้ง กระดาษ หรือข้าวเป็นต้นน้ำแท้จริง และผลผลิต asset ไม่ลอยเข้าคลังโดยไร้กระบวนการ/ต้นทุน
- เกษตรครบอย่างน้อยสองรอบปลูกต่อเนื่อง: เมล็ดถูกใช้ ผลผลิตเกิดภายหลัง คัดบางส่วนเป็นพันธุ์ แล้วปลูกรอบถัดไปได้ ดิน/น้ำ/ธาตุอาหารต่อเนื่อง
- ตรวจกรณีไม่มีเมล็ด ขาดน้ำ ธาตุอาหารต่ำ เมล็ดเก่า/งอกไม่ครบ ผลผลิตเสียหาย และเก็บพันธุ์มากจนปริมาณขายลด ไม่อ้างว่าทุกกรณีต้องเก็บเกี่ยวสำเร็จ
- ยอดเมล็ด/ผลผลิต/ของเสียและเงินต้องสมดุล การคัดพันธุ์/แปรรูป/ขาย/ซื้อ/บันทึกโหลดซ้ำไม่สร้างของซ้ำ
- ไม่สามารถใช้ข้าวสาร/แป้งเป็นเมล็ด หรือวน craft เมล็ดกับผลผลิตใน tick เดียวเพื่อปั๊มของ
- แหล่งแร่ finite ลดลงเมื่อขุด แหล่งหมุนเวียนฟื้นตามกติกา และ flow intake จำกัดตามสภาพ/อุปกรณ์อย่างเหมาะสม
- ผู้ใช้ยังเป็นผู้สังเกต NPC ตัดสินใจปลูก ซื้อปุ๋ย ใช้น้ำ กันเมล็ด ขาย และแปรรูปเอง พร้อมเหตุผลให้ตรวจดู

วิธีทำและความคิดสร้างสรรค์ให้ Gemini ตัดสินใจเองได้ แต่ห้ามลดคำกำชับนี้เป็นเพียงการเปลี่ยนชื่อ Tier โดยไม่มีผลต่อกระบวนการผลิตจริง
