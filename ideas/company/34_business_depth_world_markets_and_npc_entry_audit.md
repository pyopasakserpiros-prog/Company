## สิ่งที่มีจริงและจุดที่ควรต่อยอด

Source v2.0.0 มีวัตถุดิบ 58 ชนิด สินค้า 36 ชนิด โมเดลธุรกิจ 8 แบบ บริการ B2B 6 แบบ ประเทศ/กลุ่มเศรษฐกิจ 8 รายการ และเหตุการณ์โลก 12 แบบแล้ว ดู [project status](../../project_status_and_ai_onboarding.md) และตรวจ source ล่าสุดก่อนใช้ตัวเลขหรือรหัสใดในงานจริง

ธุรกิจติดตั้งระบบพลังงาน ผู้ค้าส่งวัสดุอุตสาหกรรม และศูนย์ฝึกทักษะให้บริษัทภายนอก **มีข้อเสนออยู่แล้ว** ใน [บท 21](21_โมเดลธุรกิจบริการใหม่_10_ประเภท_ทรัพยากร_ขั้นตอน_และผลลัพธ์.md) ข้อเสนอใหม่ควรเอารายงานที่ส่งมาไปเติมคุณภาพและความลึกให้รายการเดิม ไม่สร้างเอกสารซ้ำ:

- **ติดตั้งและดูแลระบบพลังงาน:** สำรวจหน้างาน → ออกแบบ → จองสินค้า คน และรถ → ติดตั้ง/ทดสอบ → ส่งมอบ → รับประกันและบริการหลังขาย สินค้าอย่างโซลาร์รูฟท็อปหรือระบบโซลาร์พร้อมแบตต้องใช้ชิ้นส่วนจริงและมีตลาดรองรับ รายได้ดูแลต่อเนื่องจะเกิดได้เมื่อมีสัญญา/การตรวจบริการจริง
- **ผู้ค้าส่งวัสดุ:** เสนอราคา/สั่งซื้อจาก supplier → รับและตรวจล็อต → เก็บตามอายุ/พื้นที่ → จอง stock ให้ลูกค้า → หยิบ/ส่ง → วางบิลและรับเงิน กำไรต้องหักค่าขนส่ง ค่าเก็บ ของเสีย ดอกเบี้ยเงินจมและลูกหนี้ ไม่เปิดช่องซื้อขายวนกับบริษัทเดิมเพื่อสร้างส่วนต่างฟรี
- **ศูนย์ฝึกภายนอก:** ขายรอบเรียนและผลการประเมินทักษะ ไม่ใช่ขายใบเข้าร่วม ต้องมีผู้สอน เครื่องมือ ที่นั่ง เวลา และผู้เรียนของลูกค้า การดึงผู้สอนจากบริษัทไปสอนลดกำลังทำงานเดิมได้ และต้องแยกผลฝึกของพนักงานภายนอกจากทักษะ NPC ในบริษัท

ไอเดียเหล่านี้ยังไม่ใช่ระบบที่ยืนยันว่าทำงานอยู่ในเกม การมีอาคารฝึกภายในและบริการ B2B อื่นไม่ได้แปลว่ามีธุรกิจฝึกอบรมลูกค้าภายนอกหรือธุรกิจติดตั้งพลังงานครบวงจร

รายงานธุรกิจที่แนบมาลงรายละเอียดของธุรกิจพลังงานและผู้ค้าส่ง แต่จบหลังหัวข้อความเสี่ยงของผู้ค้าส่ง ศูนย์ฝึกยังปรากฏเพียงในบทสรุป/ตารางเปรียบเทียบ และยังไม่มีข้อเสนอประเทศใหม่ จึงเติมกรอบออกแบบสำหรับสองส่วนนี้ไว้ด้านล่างให้ Gemini ต่อยอด

## ความลึกของสายโลหะที่ควรสำรวจ

Expansion Memo เสนอโมเดล Primary Metals, Alloy Mill & Scrap Loop พร้อมสินค้าตัวอย่างเช่น โพรไฟล์อะลูมิเนียม ชุดรางยึดแผงโซลาร์ และถาดแบตเตอรี่ EV ข้อเสนอมีเหตุผลตรงกับช่องว่างใน catalog แต่ตัวเลขและสูตรยังเป็นสมมติฐาน:

- ใน source มีแร่บ็อกไซต์ที่เหมืองเดิมขุดได้ แต่ไม่มีสูตรหรือสินค้าใช้ต่อ; มี iron_ore ใน catalog/initial stock แต่ยังไม่พบแหล่งขุด supplier หรือสูตรผู้ใช้
- metal_sheet ปัจจุบันเป็นวัตถุดิบเดียวที่ชื่อรวมแผ่นโลหะกับอะลูมิเนียม แต่สูตรหลักใช้ copper_iron_ore ไม่ได้แยกองค์ประกอบเหล็กกับอะลูมิเนียม ชิ้นส่วน heat_sink ใช้ metal_sheet และ copper_coil จึงควรตรวจคำอธิบาย สูตร และการใช้งานทั้งหมดก่อนเปลี่ยนความหมาย
- มี mine สำรองร่วม 420 หน่วยที่ป้อนแร่หลายชนิดอยู่แล้ว; การออกแบบแหล่งเพิ่มหรือแก้ปริมาณสำรองต้องตรวจวิธีหัก reserve, หน่วย และผลต่อธุรกิจที่พึ่งแร่เดิม
- แผนที่มี plot ขยายที่นิยามไว้ 14 จุด และยังไม่มี plot id smelterForge ใน catalog ปัจจุบัน อย่าสมมติว่ามีพื้นที่ว่างสำหรับอาคารที่ 15 จนกว่าจะตรวจ layout จริง

แนวทางที่เสนอให้ Gemini ชั่งน้ำหนักคือทำเป็นบันไดลงทุนแทนการบังคับสร้างโรงถลุงครบชุดทันที: (1) ซื้อโลหะเกรดที่ยังผลิตเองไม่ได้ (2) ขึ้นรูป/กลึงเป็นชิ้นส่วนและขายชุดประกอบ (3) เพิ่มแหล่งแร่และการแปรรูปเมื่อคน ความรู้ เงิน และตลาดพร้อม (4) ต่อ scrap/recycling หรือรับจ้างถลุงเมื่อมีลูกค้าและการแยก custody จริง เส้นทาง “ซื้อก่อน ผลิตเองภายหลัง” ทำให้บริษัททุนต่ำหรือผู้บริหารระมัดระวังยังมีทางเลือก

สูตรใน memo ต้องตรวจความสมจริงก่อนใช้: เหล็กจากแร่ต้องมีสารรีดิวซ์และฟลักซ์ตามกระบวนการที่เลือก ดีเซลไม่ควรถูกใช้แทนถ่านโค้ก/ก๊าซรีดิวซ์ในปฏิกิริยาถลุงโดยไม่มีแบบจำลองที่อธิบายได้; อะลูมินาต้องมีสารและขั้นตอนที่เกี่ยวข้อง; การถลุงอะลูมิเนียมต้องมีไฟฟ้า/วัสดุสิ้นเปลืองที่สมเหตุสมผล ไม่ใช่แค่อะลูมินาเปลี่ยนเป็นโลหะโดยไม่มีต้นทุนหรือผลข้างเคียง ส่วน red mud, slag, scrap และ reject ต้องมีทางเก็บ ขาย บำบัด หรือคืนสภาพที่ไม่สร้างผลผลิตฟรี

เริ่มจาก vertical slice ที่ใช้ได้จริง เช่น ซื้อ aluminium_ingot → รีดโพรไฟล์ด้วยกำลังผลิต/เครื่องมือที่มี → ผลิต solar_mounting_rail_kit หรือ ev_battery_tray → มีผู้ซื้อ B2B และความต้องการที่ระบบ NPC มองเห็น จากนั้นให้ผู้พัฒนาเลือกว่าควรสร้างเตา/เหมือง/บริการ toll smelting ในขอบเขตเดียวกันหรือเก็บเป็นช่วงถัดไป ไม่ต้องยึดชื่อ Model 9 หรือราคาต้นทุนที่แนบมา

## ประเทศและตลาดภายนอกที่เพิ่มทางเลือกจริง

เพิ่มประเทศด้วยแหล่งผลิตและตลาดที่แตกต่างกัน ไม่ใช่เพิ่มธงกับตัวคูณราคาอย่างเดียว ข้อเสนอด้านล่างเป็นตัวเลือกออกแบบ ไม่ใช่ข้อมูล catalog ที่มีแล้ว:

| ตลาดที่อาจเพิ่ม | จุดเด่นฝั่งจัดหา | ความต้องการสินค้าหรือบริการที่นำมาเล่นต่อได้ |
|---|---|---|
| อินโดนีเซีย | แร่นิกเกิลจากแหล่งเหมือง; ปาล์ม/ยางเป็นผลผลิตเพาะปลูก ไม่ใช่แร่ธรรมชาติ | วัสดุแบตเตอรี่คนละเคมีกับ LFP, อุปกรณ์เหมือง/ตรวจวัด, แปรรูปเกษตร และขนส่งหมู่เกาะ |
| ออสเตรเลีย | ลิเทียมจากแร่แข็ง แร่เหล็ก และธัญพืชที่ต้องปลูก | เซนเซอร์/หุ่นยนต์เหมือง ระบบพลังงานและกักเก็บ โลจิสติกส์ระยะไกลและการจัดซื้อวัตถุดิบ |
| อินเดีย | ผู้ผลิต/ผู้ซื้อในตลาดยา ซอฟต์แวร์และบริการเทคโนโลยี | อุปกรณ์การแพทย์ สินค้าปลอดเชื้อ ซอฟต์แวร์องค์กรและ cold chain; API ยาเป็นของแปรรูป ต้องมีเส้นทางผลิตหรือ supplier จริง |
| สิงคโปร์ | ศูนย์กลางท่าเรือและการค้าข้ามแดน ไม่ใช่แหล่งแร่ตั้งต้น | คลัง/3PL cold chain, การรวมเที่ยว, ตรวจคุณภาพ, ระบบ WMS/TMS และบริการองค์กร |
| ตัวเลือกถัดไป: บราซิลหรือเกาหลีใต้ | บราซิลเชื่อมเกษตรและแร่; เกาหลีใต้เชื่อมแบตเตอรี่และอิเล็กทรอนิกส์ | เลือกเพิ่มเมื่อสร้างความแตกต่างจากประเทศและกลุ่มเศรษฐกิจเดิมได้จริง |

ประเทศใหม่ควรมีอย่างน้อยหนึ่งบทบาทที่มีผลในเกม เช่น supplier ของทรัพยากรที่ระบุต้นทาง, ผู้ซื้อสินค้าจริง, คู่แข่ง/ผู้รับเหมา หรือเส้นทางผ่านที่มีต้นทุนและเวลา จากนั้นให้ regime/event กระทบ tariff, ค่าเงิน, freight/lead time, คุณภาพและมาตรฐาน, เงื่อนไขชำระเงิน หรือ demand แล้วส่งผลไปยัง order/การซื้อ/การผลิต/มติ CEO และพงศาวดารโลกตามลำดับ ผู้เล่นควรสืบเหตุได้ว่าเหตุการณ์หนึ่งทำให้บริษัทใดเปลี่ยนการตัดสินใจอย่างไร

แนวคิดเพิ่มเติมจาก Codex คือใช้ตลาด 3–4 ประเทศสร้าง “ทางเดินการค้า” ที่ผู้เล่นสังเกตได้ เช่น เหมือง/ผู้ส่งออกวัตถุดิบ → โรงงานไทยผลิตชิ้นส่วน → Singapore เป็นผู้รวมและขนส่ง → ผู้ซื้อเฉพาะตลาดอินเดียหรือออสเตรเลีย พร้อมเงื่อนไขรับรองคุณภาพ/คาร์บอนและการจ่ายเงินต่างกัน ไม่ต้องจำลอง GDP หรือทุกบริษัททั้งโลกละเอียดเท่ากัน เลือกเฉพาะตัวแปรที่เปลี่ยนทางเลือก NPC ได้

การตรวจซอร์ส v2.0.0 ยืนยันว่าแผนตัดสินใจของคณะผู้บริหารกับเส้นทางที่เรียกใช้อัตโนมัติเป็นคนละเรื่อง การที่มีโค้ด evaluator ไม่ได้แปลว่า CEO ใช้เส้นทางนั้นได้ระหว่างเล่นจริง

| พนักงานตั้งบริษัทส่วนตัว | Audit ไม่พบระบบนี้; ไม่ใช่บั๊กของ CEO บริษัท และไม่ควรแก้ Human Core เพื่อแทรกเป้าหมายใหม่ | เก็บเป็นข้อเสนออนาคตถ้ามีเหตุผลด้านเกมเพลย์ ใช้ extension ภายนอก core และอย่ารวมกับงานแก้ evaluator โดยอัตโนมัติ |

การตรวจ baseline รอบจัดทำข้อเสนอนี้: npm test ผ่าน 132/132 และ npm run check ผ่าน แต่ repro 60 วันยังยืนยันบั๊ก Critical ข้างต้น จึงไม่ควรใช้ผล suite ปัจจุบันกล่าวว่าการเปิดธุรกิจอัตโนมัติทำงานครบ

## เงื่อนไขร่วมสำหรับทุกธุรกิจ/สินค้าใหม่

1. ระบุต้นน้ำจริง แหล่งซื้อ/ผลิต หน่วย เกรด คุณภาพ ระยะส่งมอบ วัตถุดิบย่อย พลังงาน เครื่องมือ คน/ทักษะ เงินทุนหมุน และข้อจำกัด capacity
2. ผลผลิตทุกชนิดมีผู้ใช้/ผู้ซื้อที่เลือกได้จริง รวม byproduct, reject, ของเสีย และเส้นทางของสินค้าฝาก/สินค้าลูกค้า
3. วัตถุดิบแปรรูปต้องผลิตจากต้นทางที่มีจริงหรือซื้อจาก supplier; น้ำตาล แป้ง กระดาษ ข้าวสาร และสินค้าพืชผลไม่ใช่ทรัพยากรธรรมชาติตั้งต้น; พืชต้องมีเมล็ด/กล้า น้ำ ธาตุอาหาร เวลาและการหักสต็อก
4. เงินใช้หน่วย satang และ ledger; แยกต้นทุนลงทุน ค่าใช้จ่าย เงินจอง มัดจำ รายได้ที่รับรู้ และลูกหนี้ อย่าตั้งราคา/ทุนจากเอกสารตัวอย่างเป็นข้อเท็จจริงก่อนจำลองหลาย seed
5. NPC แยก “ทำไม่ได้เพราะขาดเงื่อนไข” จาก “ทำได้แต่ผู้บริหารเลือกเก็บเงิน/ทดลอง/จ้างช่วง/ฝึกคน/ปฏิเสธ” เหตุผลต้องเกิดจากทางเลือกและข้อมูลที่ระบบใช้จริง
6. ทุกสินค้า/ธุรกิจต้องเชื่อมแหล่งข้อมูล → market/order → การตัดสินใจ → resource reservation → production/service → ส่งมอบ/บัญชี → ผลต่อ NPC/บริษัท/โลกภายนอก

เอกสารนี้เป็นข้อเสนอสำหรับผู้พัฒนาเลือก ปรับ เพิ่ม และจัดลำดับใหม่ Gemini ควรสร้างแนวทางของตนเอง พร้อมรายงานสิ่งที่เปลี่ยน/คิดเพิ่มและเหตุผล ห้ามทำตามเอกสารนี้แบบท่องรายการถ้า source แสดงว่ามีทางที่ดีกว่าหรือปลอดภัยกว่า
