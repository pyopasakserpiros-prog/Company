# รับช่วงโลก Company v2.4.0

ผู้ใช้มอบหมายยกเครื่องโลกภายนอก งานทำใน main ต่อจาก a511b3e อ่าน AGENTS.md, project status, รายงาน v2.4.0 และ LIVING_WORLD_SYSTEM.md ก่อนเริ่มทุกครั้ง ไม่แก้ Human Core/กฎเหล็ก

Sourceใหม่คือ COMPANY_SOURCE/js/world.js โมดูล UMD ที่ sim.js require และ index.htmlโหลดก่อนsim การซื้อวัตถุดิบและขายB2Bมีเงิน/สต็อกคู่ค้าจริง; การเดินวันและ snapshotต้อง deterministic อ่าน test/living-world-v240.test.cjs และ campus-browser.cjs

รันใน COMPANY_SOURCE: npm run check, npm test, npm run build, npm run test:browser, node tools/benchmark.cjs ตรวจZIPสุดท้ายจากแหล่งที่แตกและบันทึกรายงานทุกครั้งตามคำสั่งผู้ใช้

ข้อเสนอสำหรับพัฒนาต่อ (ยังไม่ได้รับมอบหมายให้เริ่ม): เชื่อมงบคู่ค้าสินค้า/บริการ/ซอฟต์แวร์/กองรถกับworld accountsโดยมีreservationของเงินสัญญา; ขยายวงจรชีวภาพนอกบริษัทที่ยังไม่มี; แยกCOGS/มูลค่าสต็อก/กำไรบัญชีและภาษีจากcashflow; ทดสอบการมองเห็นเหตุ→ผลในโลกจากมุมผู้เล่นก่อนเพิ่มรายชื่อประเทศ ห้ามอ้างข้อเสนอเหล่านี้ว่าเสร็จแล้ว

พรอมต์พร้อมส่งต่อ: อ่านเอกสารข้างต้นและตรวจsourceจริง อธิบายสิ่งที่มีและข้อจำกัดก่อนเสนอการพัฒนา คิดไอเดียเพิ่มเองให้เข้ากับผู้เล่นที่ชอบสังเกตNPC เก็บรายงานการแก้ไข อัปเดตสกิล/สถานะ/เอกสาร และตรวจZIPก่อนส่งทุกครั้ง รายการอนาคตในบันทึกนี้เป็นข้อเสนอ ไม่ใช่คำสั่งเริ่มแพตช์ใหม่
