# ข้อความเสริมสำหรับส่งให้ Gemini ที่กำลังทำแพตช์

ผู้ใช้ไม่มีความรู้เขียนโค้ด ชอบเล่นเกม แต่ไม่จำเป็นต้องรู้ว่าจะพัฒนาหรืออยากได้ฟีเจอร์แบบไหนครบถ้วน ให้คุณช่วยคิด วิเคราะห์ สร้างไอเดีย และออกแบบเพิ่มเติมเองด้วย ไม่รอให้ผู้ใช้คิดทุกอย่างและไม่ทำแค่ตามรายการในพรอมต์

ผู้ใช้ชอบเฝ้าดูโลก NPC ที่ใช้ชีวิตและตัดสินใจตามนิสัยร่วมกับสถานการณ์ ชอบเปลี่ยนนิสัยคน ปรับบริษัท เพิ่มเงิน หรือเสกของ แล้วดูว่า NPC/ผู้บริหารนำทรัพยากรไปทำอะไร ทำให้เหตุและผลนี้เกิดจากการจำลองจริงและสังเกตได้ ไม่บังคับให้คนทุกนิสัยทำอย่างเดียวกัน

Edit Hub ต้องใช้ง่ายสำหรับคนไม่รู้โค้ด ใช้ชื่อและคำอธิบายไทยที่เข้าใจง่าย เลือกคน/บริษัทเป้าหมายชัด ปรับค่าได้สะดวกบนมือถือ เพิ่มเงินเป็นบาท เลือกเสกของจากรายการ และเห็นสิ่งที่เปลี่ยนกับผลที่ตามมา ไม่ต้องรู้ JSON หรือ ID ภายใน คุณเลือกวิธีออกแบบที่เหมาะเองได้ และอธิบายสิ่งที่ทำจริง/สิ่งที่ยังเลื่อนไว้ในรายงาน

AGENTS.md คือกฎเหล็ก ห้ามแก้โดยไม่ได้รับอนุญาตจากผู้ใช้โดยตรง และห้ามแก้ Human Core ที่ล็อก สิทธิให้สร้างสรรค์ยังอยู่ภายใต้กฎเหล่านี้ รักษาขอบเขตแพตช์ที่ทำอยู่ หากยังขยาย Edit Hub ไม่เสร็จให้ระบุอย่างตรงไปตรงมา ไม่อ้างว่ารองรับแล้วจากเอกสารเพียงอย่างเดียว
