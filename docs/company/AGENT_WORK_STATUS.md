## คำชี้แจงผู้ใช้เพิ่มเติมหลังส่งแพ็กเดิม

ผู้ใช้ย้ำว่าไม่มีความรู้เขียนโค้ด ทีมต้องช่วยคิด/เสนอไอเดียเอง โลก NPC ต้องสนุกต่อการเฝ้าดูและทดลองเปลี่ยนเงื่อนไข และ Edit Hub ต้องใช้ง่าย โปรดอ่าน [หลักออกแบบผู้เล่น](PLAYER_VISION_AND_DESIGN_PRINCIPLES.md) พร้อมข้อกำหนดล่าสุดว่า AGENTS.md เป็นกฎเหล็ก ห้ามแก้โดยไม่ได้รับอนุญาตจากผู้ใช้โดยตรง

บันทึกคำชี้แจงนี้ใน repo และพรอมต์แล้ว แต่ยังไม่มีการยืนยันว่า Gemini ที่กำลังทำจาก ZIP เดิมได้รับข้อความเสริม ผู้ใช้ส่ง [ข้อความเสริมนี้](GEMINI_FOLLOWUP_PLAYER_VISION.md) ให้แอปได้ตาม workflow การเพิ่มเอกสารไม่เท่ากับการพัฒนา UI หรือความสามารถใหม่ในเกมเสร็จแล้ว


## ชุดร่างสกิลที่เพิ่มใน repo

ผู้ใช้สั่งให้ Codex push ร่างสกิลขึ้น main ใน .agents/skills: เพิ่ม 14 หมวดที่ยังเป็น starter-draft พร้อมแหล่งอ้างอิงและพรอมต์ใน docs/company/SKILL_STARTER_HANDOFF งานนี้เป็นการเผยแพร่ร่าง ไม่ใช่การยกระดับ Master Skill หรือซิงก์สกิลในแอป Gemini

Gemini เป็นผู้รับหน้าที่ยกระดับตามคำสั่งผู้ใช้ แต่ยังไม่มีการยืนยันว่าแอปได้รับแพ็กสกิลเสริมหรือข้อความใหม่แล้ว งานแพตช์ธุรกิจเดิมยังคงสถานะตามตารางข้างต้น ไม่มีการเปลี่ยน source เกมจากงานนี้


ผู้ใช้ย้ำให้ Gemini ซิงก์สองสกิลเดิมทั้งในแอปและไฟล์ .agents/skills ที่ทุกเอเจนต์ใช้ร่วม มีตารางเส้นทางและเกณฑ์ยืนยันใน docs/company/SKILL_STARTER_HANDOFF/GEMINI_APP_SKILL_SYNC.md สถานะ installed app skills ยังรอการดำเนินการ/ยืนยันจาก Gemini การเผยแพร่ร่างบน repo ไม่ได้เปลี่ยนสถานะนี้


## อัปเดตกฎเหล็กตามคำสั่งผู้ใช้

ผู้ใช้อนุญาตให้เพิ่มข้อกำหนดถาวรใน AGENTS.md เรื่อง Gemini คิดและสร้างสรรค์เชิงรุก การทบทวนสกิลทุกแพตช์และซิงก์สองสกิลในแอป รวมถึงตรวจ ZIP สุดท้ายก่อนส่ง การเปลี่ยน repo ไม่ได้ส่งไฟล์ให้ Gemini ที่ใช้ ZIP เดิม ผู้ใช้ต้องส่งข้อความหรือไฟล์ฉบับใหม่ให้ Gemini จึงจะได้รับข้อกำหนดนี้ ไม่มีการยืนยันการอัปเดตสกิลในแอป
