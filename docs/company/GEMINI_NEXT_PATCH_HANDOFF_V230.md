# รับช่วง Company v2.3.0 — บริบทหลังงานความรู้ NPC

งาน Codex รอบนี้เสร็จแล้ว ไม่ใช่คำสั่งเริ่มแพตช์ใหม่ อ่าน AGENTS.md, START_HERE_FOR_AI.md และ project status ในชุดที่ได้รับก่อนทำงาน ใช้ main/ZIP v2.3.0 เป็นฐาน อย่านำ ZIP รุ่นก่อนมาเขียนทับ

- โค้ดใหม่: sim.js (วิชา/requirements/โครงการ/ซื้อเทคโนโลยี/การเรียนส่วนตัว), api.js, save.js, debug.js, campus-render.js และ build ที่สร้าง standalone สามสำเนา
- เปิดตัวละคร → ความรู้: ความรู้ติดตัว Lv1–Lv5 แม้บริษัทยังไม่มีงานใช้ ไม่ล็อกวิชาตามธุรกิจ การศึกษานอกงานจ่ายเงินส่วนตัวและใช้เวลาพัก
- เปิดบริษัท: ดูความรู้ทีม โครงการที่ทำจริง ผู้รู้/วิชาที่ขาด และแผนของผู้บริหาร แต้มรวมและการซื้อที่ดินไม่ใช่สิทธิผลิตทุกอย่าง
- ก่อนเพิ่มวิชาต้องใช้ [เทมเพลต](templates/KNOWLEDGE_SUBJECT_TEMPLATE.md), [ทะเบียน](KNOWLEDGE_SUBJECT_CATALOG.md), [คู่มือระบบ](LEARNED_KNOWLEDGE_SYSTEM.md), [แหล่งหลัก](research/KNOWLEDGE_CURRICULUM_SOURCES.md) อัปเดต source/ทดสอบและสร้างทะเบียนใหม่
- ตรวจ check/test/build/browser/benchmark ตาม README โดยใช้คำสั่งจริง ผลของรอบนี้และข้อจำกัดอยู่ใน [รายงาน](PATCH_REPORTS/PATCH_IMPLEMENTATION_REPORT_COMPANY_V2.3.0.md)
- สกิลใน repo/root อัปเดตแล้ว แต่ Codex ไม่มีเครื่องมืออัปเดตสกิลส่วนตัวในแอป Gemini เมื่อ Gemini รับงาน ให้ปรับสกิลแอปทั้งสองจาก master ปัจจุบันและระบุผลจริง

ส่วนที่ยังไม่มี: ผู้สอน NPC แบบจองเวลาเต็มระบบและใบอนุญาตวิชาชีพรายประเทศ ไม่ใช้การมีชื่อวิชาหรือเลขเลเวลแทนว่ามีระบบเหล่านี้แล้ว
