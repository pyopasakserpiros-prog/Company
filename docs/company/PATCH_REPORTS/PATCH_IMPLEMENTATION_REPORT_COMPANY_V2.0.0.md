2. **ระบบรัฐบาล 8 ประเทศมหาอำนาจและกลุ่มเศรษฐกิจคู่ค้า (`D.GLOBAL_NATIONS`):**
   - จำลองการเมืองและนโยบายเศรษฐกิจของ 8 ประเทศ/กลุ่มประเทศ:
     1. 🇹🇭 **ราชอาณาจักรไทย (`TH`):** รัฐบาลผสม BOI / รัฐบาลเกษตรสีเขียวและสวัสดิการ / รัฐบาลเทคโนแครตเร่ง EEC
     2. 🇺🇸 **สหรัฐอเมริกา (`US`):** รัฐบาลเสรีการค้า AI / รัฐบาลอเมริกาต้องมาก่อนและกำแพงภาษีนำเข้า (`+22~28%` ราคาชิป/เวเฟอร์) / รัฐบาลกรีนนิวดีลอัดฉีดพลังงานสะอาด (`+20~25%` ดีมานด์โซลาร์และ EV)
     3. 🇨🇳 **สาธารณรัฐประชาชนจีน (`CN`):** รัฐบาลเส้นทางสายไหม / รัฐบาลควบคุมโควตาส่งออกแร่ลิเธียมและซิลิคอน (`+26~38%` ราคาลิเธียม/แคโทด/ซิลิคอน) / รัฐบาลกระตุ้นการบริโภคและนำเข้าอาหารพรีเมียม
     4. 🇯🇵 **ญี่ปุ่น (`JP`):** รัฐบาลพันธมิตรยานยนต์และหุ่นยนต์อาเซียน / รัฐบาลฟื้นฟูเซมิคอนดักเตอร์และโรโบติกส์แห่งชาติ
     5. 🇪🇺 **สหภาพยุโรป (`EU`):** คณะกรรมาธิการภาษีคาร์บอนข้ามพรมแดน CBAM เข้มข้น / คณะกรรมาธิการความมั่นคงทางพลังงานและเวชภัณฑ์ยุโรป
     6. 🇸🇦 **ตะวันออกกลางและโอเปก (`ME`):** มติรักษาเสถียรภาพน้ำมันดิบ / มติลดกำลังการผลิตน้ำมันดิบเชิงยุทธศาสตร์ (`+25~36%` ราคาน้ำมันดิบ ดีเซล และเม็ดพลาสติก)
     7. 🇺🇦 **ยูเรเซียและภูมิภาคทะเลดำ (`RU_EE`):** ข้อตกลงเปิดระเบียงส่งออกธัญพืชและปุ๋ยโลก / มาตรการคว่ำบาตรและระงับส่งออกแร่แม่ปุ๋ย-ข้าวสาลี (`+30~40%` ราคาฟอสเฟต/โพแทช ปุ๋ย N-P-K และแป้งสาลี)
     8. 🌏 **ประชาคมเศรษฐกิจอาเซียน (`ASEAN`):** ข้อตกลงศุลกากรอิเล็กทรอนิกส์และการค้าเสรี ATIGA / มาตรการควบคุมโควตาสินค้าเกษตรหน้าด่าน
3. **12 เหตุการณ์ภูมิรัฐศาสตร์โลก สงคราม การปิดล้อมทางทะเล สนธิสัญญา และวิกฤตซัพพลายเชน (`D.GEOPOLITICAL_EVENTS`):**
   - **สงครามและความขัดแย้ง (`war_conflict` / `trade_war`):** สงครามและการปิดล้อมทะเลแดง–คลองสุเอซ (`red_sea_blockade_war`), สงครามปิดล้อมท่าเรือทะเลดำ (`black_sea_grain_fertilizer_war`), สงครามเทคโนโลยีและคว่ำบาตรชิป AI (`superpower_chip_embargo`)
   - **การเปลี่ยนขั้วรัฐบาลมหาอำนาจ (`regime_change`):** สหรัฐฯ ขึ้นกำแพงภาษีนำเข้า (`us_regime_tariff_shift`), พันธมิตรมหาอำนาจอัดฉีดพลังงานสะอาดโลก (`global_green_supercycle_election`), จีนจำกัดโควตาแร่ลิเธียมและซิลิคอน (`china_rare_earth_quota_shift`)
   - **ความร่วมมือและสนธิสัญญาระหว่างประเทศ (`international_cooperation`):** สนธิสัญญาการค้าเสรีอาเซียน–ญี่ปุ่น–อียู (`asean_jp_eu_free_trade_pact`), กองทุนจัดซื้อเวชภัณฑ์และอาหารสุขภาพโลก (`global_food_medical_accord`), พันธมิตรหุ่นยนต์และเซมิคอนดักเตอร์เอเชียแปซิฟิก (`apac_robotics_semi_alliance`)
   - **วิกฤตภูมิอากาศ โลจิสติกส์ และไซเบอร์ (`climate_shock` / `supply_chain_shock` / `tech_shock`):** เอลนีโญและคลื่นความร้อน (`el_nino_agri_drought`), วิกฤตตู้คอนเทนเนอร์และท่าเรือโลกแออัด (`global_port_congestion_crisis`), วิกฤตโจมตีไซเบอร์เร่งองค์กรขึ้นคลาวด์ (`global_cyber_cloud_alert`)
4. **กลไกส่งผ่านราคาเศรษฐกิจจริง & พงศาวดารโลก (`recomputeGeopoliticalMultipliers` & `worldChronicle`):**
   - ส่งผลโดยตรงต่ออัตราแลกเปลี่ยน (`fxRateBahtPerUsd`), ดัชนีราคาน้ำมันโลก (`globalOilIndex`), ค่าระวางงานขนส่ง (`globalFreightRateMultiplier`), เวลานำเข้าวัตถุดิบ (`globalLeadTimeMultiplier`), ตัวคูณราคาวัตถุดิบทั้ง 58 ชนิด (`materialPriceMultipliers`), ตัวคูณดีมานด์รายอุตสาหกรรม (`sectorDemandMultipliers`), ดัชนีตลาดหุ้น (`stockMarket.indices`), และการตัดสินใจซื้อสินทรัพย์ต้นน้ำของคณะกรรมการบริหาร NPC
   - บันทึกทุกเหตุการณ์ใน **พงศาวดารโลกภายนอก (`w.externalWorld.worldChronicle`)** และแสดงผลในแท็บใหม่ **🌍 ภูมิรัฐศาสตร์โลก รัฐบาล 8 ประเทศ & พงศาวดารโลก (Era 2.0)** รวมถึงตัวกรอง `🌍 พงศาวดารโลก/ภูมิรัฐศาสตร์` ในหน้าต่างพงศาวดารหลัก
