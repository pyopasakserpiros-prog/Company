# วิธีใช้แพ็กไอเดียและพรอมต์ส่งต่อ Gemini

แพ็กนี้เป็นเอกสารเสริมสำหรับซอร์ส v1.0.0 Debug ที่ Gemini มีอยู่แล้ว ไม่รวมซอร์ส JS/HTML หรือเกมที่แก้ใหม่

1. แนบ ZIP นี้ให้ Gemini พร้อมข้อความ: “ใช้ซอร์ส v1.0.0 Debug ปัจจุบันที่คุณมี อ่าน START_HERE_GEMINI.md ใน ZIP แล้วดำเนินแพตช์เพิ่มประเภทธุรกิจตามพรอมต์ได้เลย ข้อเสนอปรับและต่อยอดเองได้ โดยยึดกฎเหล็กและ workflow เดิม”
2. เริ่มอ่าน `START_HERE_GEMINI.md` ซึ่งเป็นสำเนาพรอมต์หลักใน `docs/company/GEMINI_NEXT_BUSINESS_PATCH_PROMPT.md` ของ repository
3. `ideas/company/` รวมคลังไอเดียบท 01–22 พร้อมสารบัญ บท 19–22 เป็นชุดธุรกิจหลักสำหรับส่งต่อครั้งนี้ บท 13–18 เป็นทางเลือกเสริม ไม่ได้บังคับทำทั้งหมด
4. `reference_rules/` เป็นสำเนากฎ ทักษะ และคู่มือจาก repository เพื่ออ่านประกอบ ไม่ใช่คำสั่งให้คัดทับไฟล์ใหม่กว่าในซอร์ส Gemini เปรียบเทียบก่อนใช้
5. ใช้ `MANIFEST.json` ตรวจรายการ ขนาด และ SHA-256 ของไฟล์ในแพ็ก สถานะ tests ในเอกสารอ้างอิงเป็นข้อมูลเก่า ต้องรันจริงในงานแพตช์

ข้อเสนอใหม่ในบท 22: ก๊าซอุตสาหกรรม ยางรถ/หล่อดอก เยื่อ/กระดาษ แก้ว สิ่งทอ คอนกรีต/Precast และธาตุอาหารพืช แต่ละสายมีวัตถุดิบ เครื่องมือ กระบวนการ ลูกค้าปลายทาง และกฎซัพพลายเชน

แพ็กไอเดียไม่ใช่ชุดเกมรุ่นใหม่ และไม่ยืนยันว่าธุรกิจที่เสนอทำงานแล้ว การเลือกขอบเขตและการส่ง ZIP เกมที่ตรวจรับแล้วเป็นงานแพตช์ถัดไปของ Gemini
