# วิธีใช้เอกสารส่งต่อ

อ่าน [workflow ระหว่างเอเจนต์และ ZIP](AGENT_COLLABORATION_WORKFLOW.md) และ [สถานะงานร่วม](AGENT_WORK_STATUS.md) ก่อนเริ่ม/รับช่วง ใช้ [พรอมต์แพตช์ปัจจุบัน](GEMINI_PRODUCT_DEPTH_AND_NPC_PROMPT.md) กับ ZIP เกมฐานที่ระบุ และดูข้อเสนอใน ideas/company บท 28–32

ผู้ใช้ส่ง ZIP/พรอมต์ให้ Gemini หรือ ChatGPT ในแอปแชต แอปส่ง ZIP โครงการที่อัปเดตพร้อมรายงานกลับผ่านผู้ใช้ Codex หรือ Agy ที่รับผิดชอบตรวจเทียบฐานกับ repo ล่าสุดก่อนรวม ไม่ unzip ทับโครงการโดยตรง

ให้ Gemini คิดไอเดียเอง ปรับและสร้างสรรค์เพิ่มเติม และตัดสินใจภายใต้กฎเหล็กได้ พร้อมอธิบายสิ่งที่เลือกทำและผลตรวจจริง ขั้นตอนทดสอบ/build และข้อห้ามแพ็ก ZIP เดิมยังใช้ตาม workflow ที่ลิงก์ไว้
