# หลักฐานและ baseline

ไฟล์เหล่านี้เป็น snapshot หรือหลักฐานของการตรวจในช่วงที่ระบุ ไม่ใช่ผลทดสอบใหม่ของ source ปัจจุบัน

- BASELINE_CATALOG_v120.json และ BASELINE_SOURCE_SHA256.json — baseline เดิมสำหรับเปรียบเทียบ
- NPC_COVERAGE_MATRIX_V1.3.0.csv — ตาราง coverage ที่รายงาน v1.3.0 อ้างอิง
- NPC_COVERAGE_MATRIX_TO_COMPLETE.csv — สำเนาตาราง coverage สำหรับติดตามรายการ

ไฟล์ coverage สองชุดมีเนื้อหาเหมือนกัน ณ วันที่จัดหมวด; เก็บทั้งสองชื่อไว้เพื่อไม่ให้ทำลายการอ้างอิงเดิม
