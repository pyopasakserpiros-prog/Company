# โจทย์ยกระดับและลองใช้สกิล

รายการนี้เป็นโจทย์ให้ Gemini ทดลอง ไม่ใช่ผลตรวจ Master Skill ผ่านแล้ว ให้ลองเทียบแนวตอบก่อนและหลังใช้สกิล ตรวจว่าหา skill ถูกและมีหลักฐานจาก source จริง ไม่ใช่เพียงเอ่ยชื่อ invariant

1. **company-gameplay-architecture** — เปิดหน้าต่างดู NPC แล้วผลจำลองเปลี่ยนแม้ไม่ได้สั่งอะไร: จะ trace การกลายพันธุ์ของ state/RNG ที่ไหน?
2. **company-npc-life-and-behavior** — ผู้เล่นเพิ่มความรอบคอบของ CEO: จะสังเกตผลอย่างไรโดยไม่บังคับว่าเขาต้องปฏิเสธทุกการลงทุน?
3. **company-executive-business-decisions** — เงินมากและตลาดรถเย็นดีแต่ไม่มีคนขับพร้อม: แยก planner ที่ขาดกับการเลือกเตรียมความสามารถอย่างไร?
4. **company-supply-chain-and-resources** — สูตรหินฟอสเฟต/โพแทช+น้ำให้ NPK มีอะไรขาด และจะแยกทางซื้อกับผลิตเองอย่างไร?
5. **company-production-and-services** — ใบงานบริการขาดอะไหล่แต่ถูกทำ paid: ต้องตรวจ transition/consumption/ledger และตัวเรียกอัตโนมัติส่วนใด?
6. **company-economy-and-accounting** — โครงการซอฟต์แวร์รับมัดจำแล้วถูกยกเลิก: เงิน ภาระส่งมอบ/คืนเงิน และกำไรควรตรวจแยกอย่างไร?
7. **company-workforce-and-careers** — วิศวกรคนเดียวรับโปรเจกต์แอปกับซ่อมภาคสนามพร้อมกัน: quota ของตำแหน่งช่วยป้องกันได้หรือยังต้องมี capacity booking?
8. **company-world-and-markets** — ข่าว supply shock เกิดขึ้นแล้วราคา/lead time/ปริมาณซื้อเปลี่ยนจริงหรือแค่มีข้อความ จะตรวจอย่างไร?
9. **company-campus-and-logistics** — รถรับเงินส่งของแล้วแต่ยังไม่กลับลาน: การรับงานใหม่ควรตรวจสถานะรถและคนขับตรงไหน?
10. **company-edit-hub-and-observability** — ผู้ใช้เสกเงินให้บริษัทแต่เข้า wallet คน: ออกแบบ flow เป้าหมายและหลักฐานหลังแก้ให้ป้องกันความสับสนอย่างไร?
11. **company-data-integrity** — เพิ่มสินค้าใน registry ได้แล้วแต่ไม่มีออเดอร์เลย: สกิลนี้รับผิดชอบถึงตรงไหนและต้องส่งต่อสกิลธุรกิจใด?
12. **company-save-system** — โหลดเซฟเสียกลางเกมแล้วกู้หน้าปัจจุบันไม่ได้: validation/assignment boundary ควรตรวจเรียงอย่างไร?
13. **company-rendering-and-performance** — Node benchmark ผ่านแต่เกมมือถือกระตุก: จะเก็บหลักฐานฝั่ง renderer โดยไม่สรุปว่าจำลองช้าได้อย่างไร?
14. **company-qa-and-delivery** — ZIP เปิดได้แต่ไม่มี .agents/skills และ source ไม่ตรง HTML: จะตรวจจาก artifact และรายงานสิ่งที่ขาดอย่างไร?

เพิ่มกรณีขอบเขตซ้อน เช่น เพิ่มรถเย็นต้องอ่านกลยุทธ์/บัญชี/โลจิสติกส์ ไม่โหลดทุกสกิลโดยไม่มีเหตุ และเพิ่มกรณีที่ไม่ควรใช้สกิลนั้น ตรวจการรักษากฎเหล็ก การไม่สร้าง tool/API ที่ไม่มีจริง และการอัปเดตสกิล/สถานะ/รายงานหลังงานเสร็จ
