# สองสกิลแอป Gemini เดิม — สำเนาอ้างอิงเท่านั้น

ไฟล์สองชุดคัดจาก repo commit f496b0b โดยไม่แก้ไข เก็บเพื่อให้ Gemini เห็นฐานเดิม ไม่ได้ติดตั้งในแอป และมีข้อความ/ตัวเลขประวัติที่ต้องตรวจแก้ ไม่ควรนำไปอัปเดตแอปตามตัวอักษรโดยไม่ตรวจ

- SKILL_COMPANY_EVOLUTION_DEV.md → app skill ชื่อ company-evolution-dev
- SKILL_COMPANY_FOR_EVERY_PATCH.md → app skill ชื่อ company-for-every-patch

หลังสร้าง Master Skill เฉพาะเกมแล้ว ให้ Gemini อัปเดตสองสกิลนี้ให้รู้จักชุดใหม่และขั้นตอนล่าสุด พร้อมอัปเดตไฟล์ที่มีในโครงการและทุกสำเนาที่ใช้งาน ถ้าแอปมีเครื่องมือจัดการ installed skills ให้ใช้และยืนยันผลจากเครื่องมือจริง หากไม่มีเครื่องมือ ให้ส่งไฟล์ที่อัปเดตและแจ้งว่ารอการติดตั้ง ไม่อ้างว่าซิงก์แอปสำเร็จแล้ว
