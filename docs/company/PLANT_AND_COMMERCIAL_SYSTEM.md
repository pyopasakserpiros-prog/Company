## กระบวนการและเจ้าของสถานะ

`COMPANY_SOURCE/js/plant.js` โหลดหลัง world.js และก่อน sim.js เก็บ `w.plant` เครื่องมือ20แบบและ routeสินค้าครบ42รายการ แยกจาก Human Core `P.route(product)` มีชื่อขั้นตอน เครื่องมือ สัดส่วนแรงงาน เวลาที่เครื่องทำเอง และอุณหภูมิเป้าหมาย สัดส่วนแรงงานรวม1 ใช้เวลาassemblyเดิมเป็นเวลางานคน แล้วบวกเวลารอเครื่อง/ตั้งอุณหภูมิจริง

เบเกอรี่: ผสม/นวด → พักแป้งและขึ้นรูป → อบ180°Cและพักเย็น; บิสกิตไม่พักหมัก; ผลิตภัณฑ์โยเกิร์ต/โปรไบโอติก: ผสม → พาสเจอไรซ์72°C → บ่ม38°Cอย่างน้อย180นาที; เวชภัณฑ์บางชนิด: เตรียม/กรอง → บรรจุพื้นที่ควบคุม → ฆ่าเชื้อ121°C; แบตเตอรี่: ตรวจเซลล์ → ประกอบ → ทดสอบโหลด60นาที; สินค้าโลหะ/กลบางชนิด: อัดขึ้นรูป → เชื่อม → ตรวจการทำงาน; กลุ่มอื่นใช้โต๊ะเตรียมงาน/ประกอบ/ทดสอบตาม route

โมเดลเป็นระดับกลุ่มกระบวนการ ตัวเลขเป็นค่าเกม **ไม่ใช่สูตรอาหาร แนวทางผลิตยา หรือมาตรฐานความปลอดภัยโรงงานจริง** ยังไม่จำลองความดัน/จุลชีววิทยา/เคมีอุตสาหกรรมเต็มรูปแบบ

แต่ละชิ้นมี `unit.process {version,index,labor,phase,history}` ประวัติระบุเครื่อง ผู้ทำ เวลาผ่านขั้น อุณหภูมิ และเวลารอจริง jobยังใช้kindassemblyเพื่อรักษาpipelineQA/แพ็ก/ส่งเดิม แรงงานถูกจำกัดที่ขอบขั้น จึงข้ามขั้นด้วยทักษะสูงไม่ได้

`P.available/stationFor/labor/tick` คุมการใช้ช่องเครื่องจักรและการรอ แต่ละเครื่องผูกกับสถานีassemblyในผังเดิมอย่างคงที่ คนต้องเดินไปสถานี ระหว่างเครื่องทำเองปล่อยพนักงานไปทำงานอื่น แต่เครื่องยังถูกจองจนจบ ช่วงรอไม่เดินซ้ำด้วยการอ่านsnapshot ต้องผ่านเวลาsimulationและเข้าใกล้อุณหภูมิเป้าหมายภายใน2°C ถ้าเครื่องเสีย/บำรุง/ไฟตก ช่วงรอหยุดได้

## เครื่องมือและงานช่าง

ชุดพื้นฐาน5แบบเป็นทุนตั้งต้น: เครื่องมือมือ สถานีบัดกรี ชุดทดสอบโหลด เครื่องพัฒนาซอฟต์แวร์ อุปกรณ์คลัง ไม่เพิ่มเงินหรือสร้างเครื่องใหม่รายวัน เครื่องเฉพาะมีเครื่องผสม เตาอบ หม้อต้ม พาสเจอไรซ์ ตู้บ่ม แท่นอัด เครื่องเชื่อม ห้องสะอาด/นึ่งฆ่าเชื้อ ห้องเย็น ชุดวินิจฉัย โรงสี ถังปฏิกรณ์ โรงงานเวเฟอร์ เตาถลุง/รีด

`P.request` ตรวจทุน18วัน หักค่าเครื่องเป็นequipment ทยอยรอส่ง2/5/14วันตามราคา (สายเวเฟอร์180วัน) แล้วต้องมีงานช่างติดตั้ง60/240/480หน่วยงานตามขนาดเครื่อง (สายเวเฟอร์4,320หน่วยงาน)ก่อนพร้อมใช้ เครื่องราคาเกิน50,000บาทต้องมีประวัติส่งสินค้าอย่างน้อย50ชิ้นก่อนพิจารณา จึงไม่ซื้อโรงงานเวเฟอร์เพียงเพราะอยากผลิตชิปจำนวนเล็กน้อย `P.review` ประเมินงานที่ต้องใช้จริงในเวลา11:15เมื่อมีCEOและautonomyเปิด

เครื่องมีcapacity,condition,status,slots,temperatureC,totalMinutes,totalKwh สภาพลดตามเวลาที่ใช้จริง .003จุด/นาที และส่งผลความเร็วแรงงาน เครื่องต่ำกว่า25หยุดใช้ บำรุงได้เมื่อสภาพต่ำกว่า55และว่าง หรือหยุดซ่อมฉุกเฉินเมื่อต่ำกว่า25แม้ค้างงาน งานค้างเครื่องถูกพักไว้และกลับหลังซ่อม

`P.maintain` หาคนทำงานที่มีความรู้ถึงเกณฑ์เครื่อง ไม่ผูกกับชื่ออาชีพเท่านั้น ความรู้maintenance/วิชาเฉพาะ ความถนัดanalytical/dexterity และความเหนื่อยส่งผลเวลา ช่างต้องเดินถึงจุดทำงาน ไม่ทำงานผลิตควบกันในtickเดียว ค่าซ่อม1.5%ค่าเครื่อง อะไหล่แบ่งกลุ่มโลหะแผ่น เรซิน/ซีล และชุดสายไฟ เบิกจากคลังจริงและบันทึก `plant.partsConsumed` ฝ่ายจัดซื้อรวมอะไหล่ที่ขาดในแผนซื้อ

ซ่อมเสร็จสภาพ75+คะแนนความรู้*.25 ไม่รับประกันเหมือนใหม่ ช่างได้ประสบการณ์maintenanceผ่านlearnSubjectของเกมที่เคารพprerequisite/potential/สภาพมนุษย์ หากไม่มีผู้รู้จะรอและขอเรียนเส้นทางวิชาที่ขาด โดยไล่prerequisiteก่อน ไม่มีการเพิ่มวิชาให้เต็มฟรี

พลังงานทุกเครื่องสะสมตามkW×นาที/60 และรวมส่วนเพิ่มในมิเตอร์รายวัน ใช้billedEnergyKwhกันคิดซ้ำ

## ธุรกิจอื่นและวัตถุดิบ

บริการB2B10แบบแมปเครื่องมือคนละประเภท เช่น สอบเทียบใช้diagnostic kit ห้องเย็นใช้cold room ถลุง/รีดใช้smelter ค้าส่งใช้warehouse tools การadvanceถูกบล็อกเมื่อเครื่องไม่พร้อมและขอซื้อ/ติดตั้งตามทุน งานซอฟต์แวร์ใช้developer PC กองรถใช้เครื่องมือจัดคลังควบกับเงื่อนไขรถเดิม เกษตร/เก็บเกี่ยว/เลี้ยงสัตว์ต้องมีเครื่องมือพื้นฐานพร้อมใช้ ไม่กำหนดให้กิจการเล็กต้องซื้อรถแทรกเตอร์เสมอ

## เงินคู่ค้าและเซฟ

`World.reserveCommercial` กันเงินทั้งก้อนจากcashของบริษัทผู้ซื้อหรือtreasuryรัฐไป `living.commercialEscrows` ไม่เพิ่มcashบริษัทเรา เมื่อรับมัดจำ/จ่ายinvoice `payCommercial` จึงย้ายเงินออกจากescrowมาledgersalesจริง เมื่อครบสัญญา `closeCommercial` คืนส่วนที่เหลือจากส่วนลดส่งช้าให้เจ้าของ การส่งบันทึกfinishedGoodsที่ผู้ซื้อ ไม่สร้างเงินอีกรอบ

สมการเงินโลกเพิ่มยอดescrowคงเหลือในสินทรัพย์โลก opening=balance+paid+returned และผูกpaidกับcommerce.paidSatang สัญญารวมมี `ordered/delivered` เท่าผลรวมออเดอร์ลูก ไม่มีการยกเลิกงวดฝ่ายเดียวผ่านcancelOrderปกติ

`Save.validate`/`S.audit` ตรวจplant/commerce/world ledger และการเบิกอะไหล่ Current saveเก็บคิวเครื่อง เวลารอ อุณหภูมิ งานช่าง เงินกัน งวดส่งและประวัติได้ เครื่องplantว่างในเซฟเก่าอาจต้องเริ่มจากทุนตั้งต้นเมื่อsimulationเดิน ไม่รับประกันเซฟข้ามรุ่นตามAGENTS
