เงินและสต็อกเริ่มต้นเป็นทรัพย์สินตั้งต้นของสถานการณ์และบันทึกใน opening; ไม่เติมซ้ำรายวัน ตลาดสำรองมี 500 หน่วยต่อวัตถุดิบเมื่อเริ่มโลก ขายแล้วลดและซื้อเติมจากผู้ผลิตจริง คลังไทยส่งหนึ่งวัน ช่วยกิจการเริ่มต้นไม่ต้องนำเข้าทุกชิ้น ไม่ใช่แหล่งสินค้าไม่จำกัด

## ประเทศและรัฐบาล

`living.nations[id]` มี treasury, householdCash, taxes, spending, wages, consumption, transfers, เงินเฟ้อ การว่างงาน ดัชนีเศรษฐกิจ ดอกเบี้ย ความนิยม เสถียรภาพ เทคโนโลยีและโครงสร้างพื้นฐาน ประเทศมีจุดเด่นต่างกันตาม profiles ใน world.js ตัวเลขเป็นสเกลเกม ไม่ใช่สถิติปัจจุบันของประเทศจริง

- ทบทวนนโยบายทุก 14 วัน: เงินเฟ้อ >5% เลือกเข้มงวด/ขึ้นดอกเบี้ย; ว่างงาน >7% เลือกกระตุ้น/ลดดอกเบี้ย; คลังเหลือน้อยเลือกสงวนเงิน; นอกนั้นรักษาสมดุล
- รัฐโอนงบเข้าตลาดครัวเรือน/อุตสาหกรรมปลายทางจริงและหักคลัง ปริมาณขึ้นกับนโยบายและเงินที่เหลือ
- เงินเฟ้อตอบสนองราคาตลาดและดอกเบี้ย การว่างงานตอบสนอง utilization ของกิจการ ดัชนีเศรษฐกิจส่งต่อถึงกำลังซื้อและอุปสงค์รายสาขา
- ทบทวนผู้นำครั้งแรกวันที่ 120–240 ตาม seed หลังจากนั้น 180 วัน ความนิยม <45 ทำให้เปลี่ยนขั้วนโยบายตาม catalog ไม่สลับรัฐบาลทุก 6 วัน
- `externalWorld.government` เป็น projection นโยบาย TH จากบัญชีนี้ ไม่สุ่มใหม่ทุก 7 วัน

## กิจการภายนอก

`living.firms[id]` เก็บเงินสด opening/receipts/payments สต็อกและ flows กำลังผลิต เทคโนโลยี ความเสี่ยง/ระมัดระวังของผู้บริหาร เงินลงทุน สถานะหยุดกิจการ เหตุผลตัดสินใจ และประวัติ 30 วัน

ผลิตจากสูตรจริง `D.MATERIAL_RECIPES.inputs/outputs` รวมผลพลอยได้และประตูเทคโนโลยีตาม tier ไม่มี input ก็ผลิตไม่ได้ มีเงินไม่พอสำรองก็หยุดกิจการ การขุดแร่ลดสำรอง น้ำ/อากาศจำกัดตามกำลังรับและโครงสร้างพื้นฐาน พืชที่มีใน AGRICULTURE_CROPS ใช้พันธุ์ น้ำ ปุ๋ย เวลางอก/เติบโต เก็บส่วนหนึ่งเป็นพันธุ์รอบใหม่ ไม่ขุดพืชออกจากแหล่งแร่ วัตถุดิบชีวภาพที่ยังไม่มีวงจรในโมดูลนี้ขายจากสต็อกเดิม/ซื้อเข้ามาเท่านั้น และแสดงเหตุผลว่าขาดวงจรผลิต

กิจการปลายทางใช้ input ที่มีจริงอย่างน้อย 1–2 แขนงและขายผลผลิตรวมให้ตลาดภายในประเทศที่มีเงินจำกัด นี่เป็นแบบจำลองกิจการรวม ไม่ใช่โรงงานรายละเอียดเท่าบริษัทหลัก

ค่าดำเนินงาน/ทุนวิจัย/ลงทุนจ่ายออกจากบริษัทและเข้าบัญชีตลาดแรงงาน/บริการปลายทาง เงินซื้อสินค้ามาจากกำลังซื้อของบัญชีปลายทาง ภาษีภายนอก 15% ของเงินสดสุทธิบวกในวันนั้นเป็นแบบย่อ ตัวเลข `profit` ใน schema เดิมของโมดูลนี้จึงแสดงใน UI เป็น **กระแสเงินสดสุทธิหลังภาษี** ไม่อ้างว่าเป็นกำไรตามมาตรฐานบัญชีหรือกฎหมายภาษีจริง

ทุก 7 วันผู้บริหารพิจารณา: ทุนต่ำกว่าสำรอง → เก็บเงิน; ขาดเทคโนโลยีและมีทุน → พัฒนาครั้งละ 2 ระดับ; utilization >72%, มีกระแสเงินสดบวก, รับความเสี่ยง >45, มีเงินเกินงบสำรอง และห่างลงทุนครั้งก่อน 28 วัน → ขยายกำลังผลิต; ต่ำกว่า35% และขาดทุน7วัน → ลดราคา/ชะลอลงทุน; มิฉะนั้นคงกิจการ เหตุผล/เงินก่อนพิจารณาบันทึกใน journal

## การค้า โลจิสติกส์ และตลาด

ผู้ซื้อหา input ที่ขาดโดยหักสต็อกและของระหว่างทางแล้ว มี buffer ป้องกันใช้เงินหมด จำกัดดีลต่อวัน เลือกผู้ขายที่มีของ การซื้อหักเงินผู้ซื้อ/เพิ่มเงินผู้ขาย/ส่งภาษีเข้าคลังประเทศปลายทาง หักของผู้ขายแล้วเก็บใน `living.shipments` จนถึงกำหนด ผู้ซื้อจึงรับของ หากเกิดสงครามระหว่างขนส่งมีความล่าช้าเพิ่มครั้งเดียว

ตลาดบันทึก supply/demand/traded/shortage/price/reasonTh รายวัตถุดิบ ราคาเปลี่ยนทีละขั้นจากส่วนต่างความต้องการและสต็อก คูณกับผลนโยบายเดิมและสถานการณ์ผ่าน `apply` ราคาสปอตใช้จัดซื้อจริงตั้งแต่วันแรก บริษัทต่างๆ มีราคาขายของตนตาม priceFactor ส่วนแบ่งตลาดภายนอกเทียบรายรับของบริษัทในสาขาเดียวกัน ดัชนีหุ้นเคลื่อนจากกระแสเงินสดรวม ไม่ใช้เลขสุ่มขึ้นลงรายวัน

`placePurchase` ขอ `World.quote` ก่อนจ่ายและสำรองสต็อกผู้ขายผ่าน `sellToPlayer`; ไม่มีสต็อก/เส้นทางปิด/เงินไม่พอราคาจริง ปฏิเสธโดยไม่ลงบัญชี สินค้าเข้าคลังหลักผ่าน purchase pipeline เดิมพร้อม lead time ของเส้นทางและสถานการณ์ ราคานำเข้ารวมภาษีที่ส่งเข้าคลัง TH ไม่คิดภาษีนำเข้าระหว่างผู้ขายไทยด้วยกัน

`sellMaterialB2B` ตรวจเงินผู้ซื้อ หักเงินและเพิ่มสต็อกผู้ซื้อก่อนรับรู้รายได้ฝั่งบริษัทเรา ข้อเสนอรับซื้อรายวันเกิดจาก input gap และเงินของผู้ซื้อจริง ไม่สุ่มให้ครบ6รายการเสมอ

## ความสัมพันธ์และสถานการณ์

66 คู่สัมพันธ์มี tension/trust/status/reason/reviewDay จากความขาดแคลน เสถียรภาพ เงินเฟ้อ และความเชื่อมั่น ทบทวนทุก14วัน; ความตึงเครียดสูงอาจเกิดข้อจำกัดและความขัดแย้ง ความร่วมมือจากความเชื่อมั่นสูงลดภาษี ภาวะสงครามใช้ภาษี/เวลาขนส่งเพิ่มและอาจปิดเส้นทาง

คำสั่งสถานการณ์เดิมยังอยู่: chip embargo เชื่อมคู่ US–CN, Red Sea เชื่อม US–ME, Black Sea เชื่อม EU–RU_EE, pact เชื่อม ASEAN–JP และอื่นๆ ตาม `scenario` มาตรการชั่วคราวกลับสภาพก่อนหน้าตามกำหนด ภัยแล้ง/พายุ/ข้อจำกัดอินโดฯ ลดกำลังผลิตผู้ขายในประเทศที่เกี่ยวข้อง 40% ชั่วคราว บาง event catalog ยังส่งผลผ่านตัวคูณเดิมโดยไม่มีคู่สัมพันธ์ใหม่

ไม่มีการบังคับสุ่มข่าวสงครามทุก5วัน เหตุการณ์อัตโนมัติหลักเกิดจากการตัดสินใจและเงื่อนไขเศรษฐกิจที่สะสม ไม่รับประกันทุกเซฟต้องมีสงคราม

## UI และสัญญาตรวจ

ปุ่ม **โลก** แถบล่าง มีภาพรวม ประเทศ/รัฐบาล บริษัทภายนอก ตลาด/วัตถุดิบ การทูต/เส้นทาง พงศาวดารโลก เลือก entity และดูเหตุผล เงิน สต็อก ข้อจำกัด ประวัติ ประเทศกดเข้าบริษัทที่เกี่ยวข้องได้ ใช้งานมือถือและ standalone และไม่เปลี่ยน RNG/สถานะเมื่อเปิดดู

`World.validate`/`S.worldAudit`/`S.audit` และ Save.validate ตรวจสมการ:

- บริษัท: cash = openingCash + receipts − payments
- สต็อก: opening + produced + bought − used − sold = stock
- รัฐ: openingTreasury + taxes − spending = treasury
- ตลาดปลายทาง: openingHouseholdCash + wages + transfers − consumption = householdCash
- เงินรวมโลก = เงินเปิดโลก + playerNetSatang (ขอบเขตการซื้อ/ขายวัตถุดิบของบริษัทหลัก)

สินค้าขนส่งยังเป็นสินทรัพย์ระหว่างทาง ไม่เพิ่มในคลังผู้ซื้อก่อนกำหนด ประวัติจำกัดขนาด World journal160, worldChronicle120, firm history30, world history60 ไม่เก็บทุกธุรกรรมตลอดไป ผลกระทบมีหลักฐานก่อนตัดประวัติ

## ข้อจำกัดที่ต้องรับช่วงอย่างตรงไปตรงมา

เป็นเศรษฐกิจรวม ไม่จำลองประชากรทุกครัวเรือน รัฐสภา พรรค/เลือกตั้งจริง กองทัพ/ยุทธวิธี หรือกฎหมายรายประเทศ ไม่มีบริษัทล้มละลาย/ควบรวมอัตโนมัติขั้นเต็ม หยุดกิจการและฟื้นได้เมื่อมีเงิน อาชีพ/วิชาของบริษัทหลักใช้ระบบเดิม ส่วนกิจการภายนอกใช้ดัชนีเทคโนโลยีและผู้บริหารแบบย่อ

ตลาดปลายทางใช้สูตรอุตสาหกรรมรวมเมื่อกิจการไม่ได้มีรายการขายวัตถุดิบ ไม่ใช่ BOM สินค้าทุกรายการ สต็อกชีวภาพบางรายการยังไม่มีวงจรผลิตในโมดูลภายนอก จึงไม่เติมให้เอง เครือข่ายภูมิภาคไม่ใช่ข้อมูลบริษัทจริง

สมการเงินโลกครอบคลุมการซื้อ/ขายวัตถุดิบและธุรกรรมในโมดูลโลก สัญญาผลิตสินค้า บริการ ซอฟต์แวร์ และกองรถของบริษัทหลักยังใช้บัญชีคู่ค้า/สัญญาระบบเดิม ไม่อ้างว่าทุกสัญญาเชื่อมกระเป๋าบริษัทภายนอกครบแล้ว การขนส่งของบริษัทหลักเก็บ lead time ตอนออกคำสั่ง/เริ่มส่ง ส่วนการปรับล่าช้ากลางทางจากคู่ขัดแย้งใช้กับ shipment ระหว่างบริษัทภายนอก

ตัวเลขนโยบาย ภาษี อัตราดอกเบี้ย การเติบโตและความสามารถเป็นค่าการออกแบบเกม ไม่ใช่โมเดลพยากรณ์เศรษฐกิจจริง
