# รายงานปรับกฎทำงาน Company จากเอกสารอ้างอิงเกมเก่า

## ฐานและขอบเขต

ฐาน repo: 545f679 บน main ผู้ใช้ส่ง AGENTS.md ของเกมเก่าเป็นข้อมูลอ้างอิง และอนุญาตให้เพิ่มเติม AGENTS.md ของ Company โดยรักษาข้อเดิม งานนี้เปลี่ยนเอกสาร ไม่มีการพัฒนาแพตช์เกมหรือยกระดับสกิลเป็น Master

## สิ่งที่นำมาปรับ

- อ่านสกิล/กฎในโฟลเดอร์ก่อนงาน ตรวจสถานะเทียบ source และเลือกสกิลจากดัชนี Company จริง
- ดุลพินิจต่อข้อเสนอ การไล่ผลกระทบ/วงจรย้อนกลับ และตรวจเส้นทางข้อมูลให้ถึงพฤติกรรมจริง เปลี่ยนตัวอย่างเป็นจัดซื้อ-สต็อก-ผลิต-ส่งมอบ-เงิน-ชีวิต NPC-ลงทุน
- มุมมองทีมพัฒนาและผู้เล่นที่ชอบเฝ้าดู NPC ภาษาไทย UI/Edit Hub และข้อแลกเปลี่ยนความสมจริงกับประสิทธิภาพ ไม่บังคับสร้างเอเจนต์เพิ่ม
- Master Skills เฉพาะเกม เอกสาร/สถานะ/รายงานตามผลจริง รักษาข้อเดิมเรื่องซิงก์สองสกิลแอป Gemini และความคิดสร้างสรรค์เชิงรุก
- ZIP โครงการครบ รวม .agents, directory entries, central directory/CRC, รายชื่อ/แฮช, ทดลองแตกและตรวจจากไฟล์ที่แตก แจ้งขนาด/แฮชและตรวจปลายทางเมื่อเข้าถึงได้
- เอกสารรับช่วงและพรอมต์ถัดไปพร้อมส่งต่อผ่านผู้ใช้ แยกข้อเสนอจากงานที่อนุมัติ ไม่เริ่มแพตช์ต่อเองหรือใช้แผนรุ่นเกมเก่า

## สิ่งที่ไม่นำมาใช้

ไม่คัดระบบต่อสู้ วิถี/ตบะ/สำนัก ไอเทม/เอฟเฟกต์ แผนระยะหรือรุ่น JS2, GAME_SOURCE, fingerprint/สูตร Human Core เก่า, คำสั่ง build/test เก่า, จำนวนเทสต์ และเกณฑ์เวลาหรือสิทธิผ่อนเกณฑ์ของเกมเก่า คงกฎ Human Core SHA-256, บัญชีสตางค์, simulation/API, ผู้เล่นสังเกตการณ์ และนโยบายเซฟของ Company เดิมทั้งหมด

## ไฟล์ที่เปลี่ยนและผลตรวจ

เพิ่มเนื้อหาใน AGENTS.md; เพิ่มบันทึกในทะเบียนงานและสถานะสองสำเนา; เพิ่มรายงานนี้ในสองโฟลเดอร์และดัชนี ไม่มีไฟล์เกม/สกิลถูกแก้หรือลบ

ตรวจ git diff --check, ลิงก์ใน AGENTS.md, การมีสกิลที่ระบุชื่อจริง, ข้อเดิมทุกบรรทัดยังอยู่ตามลำดับ และรายงานสองสำเนาตรงกัน ไม่รันเทสต์เกม/build เพราะเปลี่ยนเฉพาะเอกสาร ไม่สร้าง ZIP ในงานนี้

อ่านสกิล company-qa-and-delivery และดัชนีแล้ว คงร่างสกิลไว้ตามงานที่ผู้ใช้มอบ Gemini ยกระดับ ส่วนขั้นตอนตรวจ ZIP เพิ่มในกฎเหล็กที่สกิลร่างอ้างให้อ่านอยู่แล้ว ไม่อ้างว่าได้ประเมิน Master Skills หรืออัปเดต installed skills ในแอป
