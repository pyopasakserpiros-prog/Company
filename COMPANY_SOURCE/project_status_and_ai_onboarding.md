## เกมปัจจุบัน

Company เป็นเกมจำลองบริษัทหลายอุตสาหกรรมและชีวิตพนักงานในพื้นที่บริษัท ผู้เล่นปรับเวลาและมุมมอง ตรวจข้อมูลพนักงาน/กิจการ และใช้ Edit Hub ทดลองแก้ข้อมูลที่อนุญาต ขณะที่ NPC และผู้บริหารรับงาน จัดซื้อ ผลิต ส่งมอบ บริหารเงิน ลงทุน และใช้ชีวิตตามระบบจำลอง บุคลิกและสถานการณ์มีผลต่อการตัดสินใจ เป้าหมายคือดูโลก NPC ดำเนินไปและสังเกตผลเมื่อเปลี่ยนเงื่อนไข

Source หลักอยู่ใน `COMPANY_SOURCE/` ประกอบด้วย runtime แยกโมดูล, Canvas UI, API, ระบบบันทึก, tools และ tests; `CompanyFoundation_single.html` สร้างจาก source ด้วย `npm run build` เพื่อเล่นออฟไลน์ ไม่แก้ HTML build แทน source

## ความสามารถตามฐาน v1.2.0

- บุคลิก ค่านิยม ความถนัด/ศักยภาพ และสภาวะมนุษย์อยู่ใน Human Core ที่ล็อก แก้ข้อมูลรายบุคคลผ่านเครื่องมือที่รองรับได้โดยไม่เปลี่ยนสูตรแกน
- พนักงานมีสายอาชีพ โครงสร้างองค์กร การประเมินและตัดสินใจเลื่อนขั้น การสรรหา งานประจำวัน ความสัมพันธ์/ชีวิตส่วนตัว และระบบความเป็นอยู่ตามรุ่นที่พัฒนา
- บริษัทมีแค็ตตาล็อกหลายอุตสาหกรรม ผลิตภัณฑ์/วัตถุดิบ สูตรการผลิต คุณภาพ เครื่องจักร สินทรัพย์และอาคาร โลจิสติกส์ B2B และบริษัทภายนอก
- v1.2.0 แยกคลาสทรัพยากรต้นน้ำแท้จากเมล็ดพันธุ์ ผลผลิตเกษตร/ปศุสัตว์/ป่าไม้ และวัตถุดิบแปรรูป มีวงจรเกษตร 8 ขั้นที่รายงานระบุ รวมวงจรปศุสัตว์ เหมืองสำรองจำกัด และป่าไม้หมุนเวียน
- v1.2.0 ระบุ 8 โมเดลกระบวนการธุรกิจ ได้แก่ อาหาร/เบเกอรี่, อิเล็กทรอนิกส์/เคลม, ยานยนต์/ตั้ง tooling, การแพทย์/คลีนรูม, ทรัพยากรต้นน้ำ, ขนส่ง B2B, ซอฟต์แวร์/SaaS และบริการวิศวกรรม B2B แต่ละโมเดลมีวงจรและข้อจำกัดเฉพาะตามรายงาน ต้องดู source/call-site เพื่อยืนยันรายละเอียดเมื่อจะขยาย
- ระบบเศรษฐกิจใช้สตางค์จำนวนเต็มและบัญชีรายการ; simulation เป็นเจ้าของเวลา/สถานะ/RNG ส่วน UI อ่าน snapshot และส่งคำสั่งผ่าน API
- เกมเปิดจากไฟล์เดี่ยวหรือ `index.html` ผ่าน local server; รายละเอียดวิธีเล่น ติดตั้ง และคำสั่งตรวจอยู่ใน [วิธีเปิดและพัฒนา](README.md)

## สถานะการตรวจ

ตัวเลข test/build/benchmark ในตารางประวัติเป็นผลที่รายงานไว้ในรายงานแต่ละแพตช์ ไม่ได้รันใหม่เพื่ออัปเดตเอกสารนี้ การตรวจรอบนี้อ่าน version declaration ใน source/package, รวบรวมรายงานและตรวจลิงก์/สำเนาสถานะ ไม่ได้ทดสอบพฤติกรรมทุกระบบ

รายงาน v1.2.0 ระบุ 127/127 tests ผ่านและ benchmark 0.994 ms/tick ที่ 500 NPC; ให้ถือเป็นผลของรอบนั้น ไม่ใช่ผลปัจจุบันที่ตรวจซ้ำในวันที่เอกสารนี้อัปเดต ใช้คำสั่งปัจจุบันใน README เพื่อยืนยันก่อนปล่อยแพตช์ใหม่
